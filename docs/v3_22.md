### P4 delay-protect (v3.22.1) detail

The bench (`eval_aec_challenge.py`) pre-aligns the reference with full-signal
GCC-PHAT, then the in-pipeline AEC3 matched filter runs on top. On weak/nonlinear
cases the correlation surface is flat → it latches a noise peak at confidence 1.0
(kZogUfYc +96 ms, 9xjhi +188 ms, JjCzlhn3 +96 ms), double-shifting the
already-aligned reference and collapsing ERLE. The guard rejects the heavy first
acquisition (tap reset + shift) when the filter is already cancelling. Windowed
ERLE (TC ≈ 10 s) is the signal: it decays, so a *real* path change lifts the guard
and re-acquisition proceeds; instant-ERLE EMA is too noisy, the 10-frame >5 dB
latch too strict.

**Production unaffected** (raw reference, no GCC pre-align → matched filter locks
true 16–32 ms; cold filter ERLE ≈ 0 < 2.5 → guard never blocks legit cold
acquisition). The win is a bench-measurement-artifact recovery. Casualties
(W0zK3dv0 DT_movement −0.32; JtodX/wlAXM0iD FS_movement) are audio-verified
AECMOS movement-quirks (near-only frames byte-identical; echo-dominant sections;
temporal-redistribution scoring), not regressions. **Not closed**: phantom
mislocks where the filter had not converged when the spurious acquisition fires
(weak early far, e.g. JjCzlhn3) — a fuller fix is a bench-harness change
(deferred). Env override `AEC_DELAY_PROTECT=0|1`.

## 2. Phase 0/1 re-audit — "linear was broken all along" REFUTED

The arc was done under a suspicion that the linear filter was chronically broken,
starving the ERLE→RES back-end, so prior fixes were band-aids. **Refuted**: the
substrate is sound — the linear filter is at its **LS-optimal ceiling**, the
handoff is correct, and the RES preserves near-end.

**Bottom line: NO shipped verdict and NO closed-FAIL aggregate verdict flips —
they all STAND.** Every shipped change (F2.3, F2.4, F3.1v3, E2, v3.21.2, Sprint
A, v3.21.6 P1, v3.22.0 split floor, v3.22.1 P4) was substrate-independent or
*congruent* with the fix. Arcs *blocked* by the linear bugs (Sprint C reverb,
Sprint C2 / U4.A H_error selectors) are **DISSOLVED** — their blocker was the bug,
already fixed.

**Four re-test candidates (pre-v3.21.6, hard-FS-ERLE-dependent) — all closed, no
FS-echo action:**

1. **P58 Phase 2 (RES restructure) — DISSOLVED.** Production *already runs* the
   exact P58 architecture (ErleEstimator + mode-switched ResidualEchoEstimator
   `R²=S²/ERLE | R²=X²·gain²` + Wiener SuppressionGain); the legacy 4-cap
   `ResFilter` was deleted (651ccdd). No toggle to re-test; it shipped on the
   sound substrate.
2. **v3.18 C.E (surgical RES migration) — DISSOLVED.** Production already gates RES
   on `fq_usable` via `usable_linear_estimate()` (aec_state.py:139); the legacy
   5%-coverage latch no longer gates RES.
3. **v3.14 per-band ERL — FALSE LEVER (code-verified).** Real per-band/scalar
   divergence exists (~2.7 dB median, up to +10 dB on UmlD9X38) but `_erl_estimate`
   **never feeds the echo R²** (the render-power branch uses constant
   `echo_path_gain = 1.0`, AEC3-style). Feeding per-band ERL in would give
   R²=X²·erl < X²·1 → *less* suppression → *more* echo (wrong direction). ERL's
   real consumers are all broadband. Closed.
4. **v3.13 gain-floor audit — CONFIRMATORY, no action.** Audited floors no longer
   exist (ResFilter retired; epc_dt_cap dead). Modern split-floor binding rate
   dropped 25–50 pp on the sound substrate (qNvSMyU 97%→61–73%) → the old floors
   *were* partly band-aiding the under-credited RES, but v3.22.0 already re-tuned
   this surface. A lighter floor remains a true requirement. Verdict stands.

**Upside cap**: the FS gap to AEC3 is ~47% irreducible nonlinear (needs
Volterra/NN) + ~43% RES-depth Pareto, linear at LS-optimal ceiling. Within pure
DSP there is **no remaining free FS-echo lever** — only a per-band DT-detector for
near-end preservation (a large new build, on a dimension we already lead AEC3 on).

## 7. Track C — per-bin near-end SPP (near-gated cohxd) — NULL

**Goal.** cohxd is the biggest echo win on the Pareto table (DT echo 4.318, beats
AEC2), blocked only by a DT-deg trade because Γ²(X,Y) is echo-confidence and blind
to co-present near-end. The bet: a per-bin estimate of "is near-end present in
this bin right now" lets the floor release apply *only where near-end is absent*,
which would *move* the frontier instead of trading along it.

**Mechanism (`NearendSpp`, default-OFF substrate).** Reference-based IMCRA: per
bin, track the minimum over a sliding window of the residual-to-reference ratio
`|E|²/R²` (R² = the RES reverb/echo-path-aware estimate). Far-only echo — incl. a
decaying reverb tail — stays explained by R², so the ratio sits at its floor;
genuine near-end adds energy R² does not model, spiking the ratio above the floor.
A dB-spike → sigmoid → `p_ne[k] ∈ [0,1]`. Uses the reliable reference (not Ŷ/ERLE),
and multi-frame minima separate a near-end onset from a reverb tail — the wall
that closed every single-lag-coherence discriminator (Jung-2011, Enzner-Vary).
Consumer: cohxd near-gate scales the floor *release* by `(1 − p_ne)` (errors are
safe-direction — an over-high p_ne only withholds release, never raises the floor
above base → worst case = no cohxd).

**Step 0 — audio-proof (synthetic-DT, `python/spp_step0_diag.py`).** v1 with fast
time constants (`alpha=0.2`, `minima_subwindow=60`) FAILED — far-only echo spikes
read as near-end (`p_ne ≈ 0.6` everywhere, no separation). Root cause: the
instantaneous `|E|²/R²` transfer is too variable on real far-only speech. Fix:
slow time constants (`alpha=0.02 ≈ 500 ms`, `minima_subwindow=200 ≈ 2 s`) →
separation +0.15…+0.51 (far-only / DT / reverb-tail correctly ordered). **The
slow constants are load-bearing** (near talk-spurts are sustained ~seconds; the
far-only residual + R² lag fluctuate fast — heavy smoothing averages out echo
transients but keeps near-end).

**Step 1 — 800-case A/B.** cohxd vs near-gated cohxd at `spike_thr_db = 5` and
`= 11`, vs C_pb28 baseline:

| Config | DT echo | DT deg |
|---|---|---|
| plain cohxd (−45) | 4.318 | 2.083 |
| near-gated cohxd (thr 5) | ~matched | on the cohxd line (Δdeg ≤ ±0.012 at matched echo) |
| near-gated cohxd (thr 11) | ~matched | on the cohxd line (Δdeg ≤ ±0.012 at matched echo) |

**Verdict: NULL — the near-gate does NOT move the DT frontier.** Both near-gate
operating points lie *on the plain-cohxd Pareto line* (matched-deg Δ ≤ ±0.012).

**Root cause (the bin-overlap wall).** In real double-talk the near-end and the
echo occupy the *same* frequency bins at the same time (voice-on-voice). A per-bin
near-mask therefore cannot find bins that are "echo-only and near-absent" to
release suppression on without also touching the co-present near-end — exactly the
co-presence that blocks cohxd in the first place, now visible per-bin. Step 2
(general floor modulation by the same p_ne) was SKIPPED: same p_ne, same wall,
would land on the same line. This is the per-bin restatement of the same wall the
single-lag coherence discriminators hit ([[project_dt_overuppression_audit]]).

**Disposition.** `NearendSpp` + the near-gate stay default-OFF research substrate
(byte-equal, 14/14); `spp_step0_diag.py` kept as the audio-proof harness. The
live frontier bet moves to the cohde / MMSE-LSA fork (§6.d) on the clean
post-substrate-fix baseline.
