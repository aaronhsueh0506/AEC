AEC 如何呼叫使用 — AEC/c_impl

概要

單聲道 AEC(Aec)一個實例處理一支 mic 與一路 ref。整合者只需要 aec.h(殘留回音抑制增益在 Aec 或陣列實例內,沒有獨立的公開介面)。本頁給呼叫順序、最小可編譯範例、初始化／對齊／錯誤處理／reset／destroy 規則;時序圖見 aec_sequence,參數見 外部參數 與 內部參數。下列範例 A–D 已在暫存複本以 -Wall -Wextra -Werror 對 aec.h 編譯,並在靜音輸入上跑完(含 aec_process 與 aec_process_linear + aec_process_residual 兩條路),識別字全部存在;app_read_hop 等是呼叫端自己的音訊 I/O。範例 E(四麥克風陣列實例)同樣以 -Wall -Wextra -Werror 編譯,並以測試用的 beamformer 與合成替身跑完 50 個 hop,所有回傳都是 AEC_OK。

1. Include 與連結

#include "aec.h"        /* AEC/c_impl/include/aec.h:標準整合只需要這一個 */

cc -std=gnu99 -O2 -ffp-contract=off app.c \
   -I<AEC>/c_impl/include -I<audiolib>/common/include \
   "$(make -s -C <AEC>/c_impl print-lib-path)" "$(make -s -C <audiolib>/common print-lib-path)" -lm -o app

libaec.a 不含共用 DSP,libaudio_common.a 一定要一起連結;-ffp-contract=off 是必要旗標(Makefile 會 append 在最後,見 AEC API §11)。aec.h 會 include audiolib 的 fft_wrapper.h／hpf.h,所以兩個 include 路徑都要給。輸出路徑含設定雜湊,用 print-lib-path 取,不要自己拼。

2. 呼叫順序

#步驟函式失敗時
1取得完整設定(不要手填)aec_config_from_level(&cfg, level, sample_rate)(或 aec_config_defaults)無回傳;不認得的 level 值靜默退回 balanced;取樣率不是 8000／16000／48000 時 fft_size 與 filter_length 都是 0,aec_get_mem_size() 回 0、aec_init() 回 NULL、aec_create() 回非 0
2只覆寫外部欄位(fft_size、delay_mode…)直接寫 cfg.*下一步才會被驗證
3(選用)確認格點aec_resolve_signal_grid(sr, fft, &grid)、aec_default_fft_size(sr)回 AEC_ERR_ARG(不動 *out);成功回 AEC_OK(0)
4查記憶池大小(pool 路徑)aec_get_mem_size(&cfg);拆解用 aec_get_mem_breakdownaec_get_mem_size 回 0(不是負值);aec_get_mem_breakdown 回 AEC_ERR_ARG,成功 AEC_OK
5建立實例pool:aec_init(mem, bytes, &cfg);heap:aec_create(&aec, &cfg)aec_init 回 NULL(cfg 無效、未 16-byte 對齊、pool 過小);aec_create 回 -1
5a(選用)記憶池描述子;陣列實例(n_mics = 4)建議使用aec_get_mem_requirements(&cfg, &req) + aec_init_ex(mem, bytes, &cfg, &req)前者回 -1(cfg 無效、req 清零);後者回 NULL(同 aec_init,另加描述子與目前建置不符)。陣列的池大小隨 residual 改變,見範例 E
6取每次呼叫的樣本數aec_hop_size(aec)NULL 回 0
7每個 hop 處理一次aec_process(aec, mic, ref, out) 或 aec_process_linear(aec, mic, ref) + aec_process_residual(aec, NULL)回傳 AecStatus(AEC_OK = 0;AEC_ERR_ARG／AEC_ERR_MODE／AEC_ERR_SEQUENCE 為呼叫錯誤,實例原封不動);長度由呼叫端保證
8(選用)讀 seam／狀態aec_get_residual、aec_get_linear、aec_debug_status、aec_linear_is_cancellingaec_get_residual／aec_get_linear:struct_size 要先設;NULL 或太小回 AEC_ERR_ARG(太小時不寫你的結構);aec_debug_status:NULL 時靜默 no-op;aec_linear_is_cancelling 對 NULL 回 0
8a陣列實例的每個 hop(取代 7、8)aec_process_linear(aec, mics, ref)(mics 交錯 float[hop][4])→ aec_get_array → 呼叫端 beamformer → aec_process_residual(aec, &beam) → aec_apply_gain／aec_apply_cngaec_process() 回 AEC_ERR_MODE;STATE 的 aec_process_residual 回 AEC_ERR_MODE;FULL 同 hop 第二次回 AEC_ERR_SEQUENCE;lane 或融合拒絕該 hop 回 AEC_ERR_DSP 且實例已被重設
9(選用)hop 之間調整aec_set_level(aec, level);aec_apply_external_realign(僅單聲道 EXTERNAL_ALIGNED)回 -1 且什麼都沒寫(陣列實例也回 -1:它自己對四條 lane 做 realign)
10串流邊界aec_reset(aec)NULL 為 no-op
11收尾aec_destroy(aec),pool 由呼叫端自己回收NULL 安全

3. 範例

A. 呼叫端記憶池(板端路徑,零 heap)

#include <stdlib.h>
#include "aec.h"

/* The application's own audio I/O: fills one hop of mic/ref, returns 0 at end of stream. */
extern int  app_read_hop(float *mic, float *ref, int hop);
extern void app_write_hop(const float *out, int hop);

int run_aec_pool(int sample_rate)
{
    AecConfig cfg;
    aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, sample_rate);
    /* Override only external fields here, e.g. cfg.fft_size = 512 (16 kHz). */

    size_t bytes = aec_get_mem_size(&cfg);            /* 0 = cfg rejected */
    if (bytes == 0) return -1;
    void *pool = NULL;
    if (posix_memalign(&pool, 16, bytes) != 0) return -1;   /* base must be 16-byte aligned */

    Aec *aec = aec_init(pool, bytes, &cfg);           /* NULL = bad cfg / unaligned / too small */
    if (!aec) { free(pool); return -1; }

    int hop = aec_hop_size(aec);                      /* exactly this many samples per call */
    float *mic = malloc((size_t)hop * sizeof *mic);
    float *ref = malloc((size_t)hop * sizeof *ref);
    float *out = malloc((size_t)hop * sizeof *out);
    int rc = (mic && ref && out) ? 0 : -1;

    while (rc == 0 && app_read_hop(mic, ref, hop)) {
        aec_process(aec, mic, ref, out);              /* void: no per-call error code */
        app_write_hop(out, hop);
    }

    free(mic); free(ref); free(out);
    aec_destroy(aec);                                 /* pool instance: frees nothing (only marks the handle destroyed), the pool stays yours */
    free(pool);
    return rc;
}

B. Heap(桌面／測試)

#include "aec.h"

int run_aec_heap(void)
{
    AecConfig cfg;
    Aec aec;                                          /* the struct is owned by the caller */
    aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, 48000);
    if (aec_create(&aec, &cfg) != 0) return -1;       /* -1: cfg rejected or allocation failed */

    /* ... aec_process(&aec, mic, ref, out) once per hop ... */

    aec_destroy(&aec);                                /* frees the single internal arena: exactly once */
    return 0;
}

C. hop 之間的控制呼叫

#include "aec.h"

/* Calls made between two hops, serialised with aec_process*(); not thread-safe. */
int control_between_hops(Aec *aec, int stream_boundary, int user_wants_stronger)
{
    if (user_wants_stronger) {
        /* Walk the far-active floor to the new level over 100 ms; -1 = rejected, nothing written. */
        if (aec_set_level(aec, AEC_LEVEL_AGGRESSIVE) != 0) return -1;
    }
    if (stream_boundary) {
        aec_reset(aec);          /* independent stream next: clears runtime state, keeps cfg and memory */
    }
    return 0;
}

/* Only for delay_mode == AEC_DELAY_EXTERNAL_ALIGNED: the caller changed its far alignment by delta_samples. */
int external_alignment_changed(Aec *aec, int delta_samples)
{
    int r = aec_apply_external_realign(aec, delta_samples);
    return r;                    /* 1 = learned IR shifted, 0 = filter reset, -1 = NULL or wrong delay_mode */
}

D. 只拿線性結果與頻域 seam(後級在下游)

#include <stdlib.h>
#include "aec.h"

extern int  app_read_hop(float *mic, float *ref, int hop);
extern void app_consume_frame(const AecResidualView *rv, const AecLinearView *lin);

/* Linear AEC only; the residual-echo stage is done downstream from the frequency-domain seam. */
int run_aec_seam(int sample_rate)
{
    AecConfig cfg;
    Aec aec;
    aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, sample_rate);
    cfg.residual = AEC_RESIDUAL_FULL;   /* the post block runs and fills the view; the split entry points apply nothing */
    if (aec_create(&aec, &cfg) != 0) return -1;

    int hop = aec_hop_size(&aec);
    float *mic = malloc((size_t)hop * sizeof *mic);
    float *ref = malloc((size_t)hop * sizeof *ref);
    int rc = (mic && ref) ? 0 : -1;

    while (rc == 0 && app_read_hop(mic, ref, hop)) {
        AecResidualView rv = { .struct_size = sizeof rv };
        AecLinearView lin = { .struct_size = sizeof lin };
        if (aec_process_linear(&aec, mic, ref) != AEC_OK ||       /* no out buffer */
            aec_process_residual(&aec, NULL) != AEC_OK ||
            aec_get_residual(&aec, &rv) != AEC_OK ||              /* error_spec, r2, comfort_noise, res_gain, ... */
            aec_get_linear(&aec, &lin) != AEC_OK) {               /* aligned_far_hop, delay_state, generation */
            rc = -1;
            break;
        }
        app_consume_frame(&rv, &lin);                  /* read now: pointers die at the next process call */
    }

    free(mic); free(ref);
    aec_destroy(&aec);
    return rc;
}
seam 路徑要 residual 不是 OFF(預設 FULL 即可),並用 aec_process_linear + aec_process_residual 驅動:OFF 時沒有後級,aec_get_residual 回 AEC_ERR_MODE,error_spec／res_gain／r2／comfort_noise／formed_hop 都拿不到。ESTIMATE 不算 res_gain,STATE 連 r2／comfort_noise 也不算。enable_cng 只管 aec_process() 在 FULL 時時域輸出內的舒適噪音注入;rv.comfort_noise(PSD)只要後級有跑就會算,與 enable_cng 無關。AecResidualView／AecLinearView 的指標在下一次任何 process 或 reset 呼叫後失效,要跨 hop 就自己複製。

E. 四麥克風陣列實例(n_mics = 4)

#include <stdint.h>
#include <stdlib.h>
#include "aec.h"

/* 呼叫端自己的元件(不在函式庫內) */
void app_beamform(const AecArrayView *av, Complex *weights, Complex *beam_error);
void app_reset_ola(void);                  /* 清自己的 OLA 尾巴 */
void app_synthesize(const Complex *spec);  /* 反轉換 + overlap-add */

/* 建立:一次 init 放進四條 lane、共用 delay 估計器、對齊後 far 與融合緩衝 */
Aec *app_open_array(void **pool_out)
{
    AecConfig cfg;
    AecMemReq req;                         /* 描述子:本次建置需要的記憶池 */
    void *pool = NULL;
    Aec *aec;

    aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, 16000);
    cfg.n_mics = AEC_ARRAY_MICS;           /* 4:陣列實例;residual 預設 FULL */
    cfg.capture_proxy_channel = 0;         /* 共用 delay 估計器吃哪一路 mic */
    if (aec_get_mem_requirements(&cfg, &req) != 0) return NULL;      /* cfg 無效 */
    if (posix_memalign(&pool, 16, (size_t)req.bytes) != 0) return NULL;
    aec = aec_init_ex(pool, (size_t)req.bytes, &cfg, &req);
    if (!aec) { free(pool); return NULL; } /* 池太小／未對齊,或描述子與目前建置不符 */
    *pool_out = pool;
    return aec;
}

/* 一個 hop:mics 是交錯的 float[hop][4],ref 是 float[hop];g_nr 可為 NULL */
int app_run_hop(Aec *aec, const float *mics, const float *ref,
                const float *g_nr, uint32_t *last_serial)
{
    static Complex weights[AEC_ARRAY_MICS * 129];   /* 聲道優先 [4][n_freqs] */
    static Complex beam_error[129], spec[129];      /* 16 kHz / 256:n_freqs = 129 */
    AecArrayView av;
    AecBeam beam;
    int rc;

    rc = aec_process_linear(aec, mics, ref);        /* 共用 delay + 四條 lane */
    if (rc != AEC_OK) return rc;

    av.struct_size = sizeof av;
    rc = aec_get_array(aec, &av);                   /* 各 lane 的 error_spec */
    if (rc != AEC_OK) return rc;
    app_beamform(&av, weights, beam_error);

    beam.weights = weights;
    beam.beamformed_error = beam_error;             /* 或 NULL:由權重重建 */
    rc = aec_process_residual(aec, &beam);          /* 融合 + 一次 G_res */
    if (rc != AEC_OK) return rc;

    if (aec_post_reset_serial(aec) != *last_serial) {
        app_reset_ola();                            /* 在本 hop 的 OLA push 之前 */
        *last_serial = aec_post_reset_serial(aec);
    }
    rc = aec_apply_gain(aec, g_nr, spec);           /* spec = base * min(G_res, g_nr) */
    if (rc != AEC_OK) return rc;
    rc = aec_apply_cng(aec, g_nr, spec);            /* 同一個 g_nr */
    if (rc != AEC_OK) return rc;
    app_synthesize(spec);
    return AEC_OK;
}
陣列實例的要點:權重是聲道優先的 Complex[4][n_freqs],融合為 Σ w · lane(不取共軛),必須有限且不全為零,否則 aec_process_residual() 回 AEC_ERR_ARG 且該 hop 保持開啟;beamformed_error 由呼叫端持有並活到本 hop 檢視讀完,或傳 NULL 由權重重建;含非有限值同樣回 AEC_ERR_ARG(實例不重設)。residual 三種值(OFF 被拒絕)的差別:STATE 只有四條 lane,aec_process_residual() 回 AEC_ERR_MODE,波束後的頻譜由呼叫端自己渲染;ESTIMATE 融合但不算增益(aec_apply_* 回 AEC_ERR_MODE),同一 hop 可重複融合;FULL 另算一次 G_res,同一 hop 的第二次 aec_process_residual() 回 AEC_ERR_SEQUENCE。aec_get_residual() 在陣列上 formed_hop 與 echo_spec 為 NULL。aec_process()、aec_apply_external_realign() 在陣列上被拒絕。aec_post_reset_serial() 是四條 lane 的計數之和(aec_reset() 前進 4),只比較是否與自己存的不同。完整契約見 AEC/docs/reference/integration.md §8.8。
目前尚未做到:遠端側狀態仍是每條 lane 各一份(共用的是 delay 估計器、對齊後 far、FFT 控制代碼,以及 hop 內由 lane 0 借給 lane 1–3 的遠端 FFT 結果)(16k/256 每條 ESTIMATE／FULL lane 147,200 B,四條共 588,800 B,約占 FULL 陣列池 720,352 B 的 82%;STATE lane 不切殘餘回音估計器與舒適噪音陣列,每條 124,880 B)。陣列的 STATE／ESTIMATE／FULL 池大小在 16k/256 為 616,912／712,448／720,352 B(主機實測;以 aec_get_mem_requirements() 為準)。

4. 初始化、對齊、錯誤處理、reset、destroy

項目規則(出處)
輸入長度mic／ref／out 各恰好 aec_hop_size() 個 float32,標稱 [-1, 1];處理函式沒有長度參數、不檢查(給少＝讀未初始化記憶體)。mic、ref、out 可互相 alias(aec_stage_linear 開頭就複製進內部 buffer)。
池對齊與大小基底 16-byte 對齊,aec_init 在寫任何 byte 前檢查(aec.c aec_init);mem_size 少 1 byte 即 NULL。Aec 結構本身也在池內。大小與格點、backend、struct 大小有關,永遠以 aec_get_mem_size() 為準。
查大小與 init 用同一份 cfg兩者各自驗證與計算,傳不同 cfg 不會被偵測(只擋 mem_size < need)。
init-time immutablesample_rate、fft_size、filter_length、n_partitions、delay_mode、delay_num_filters、fixed_delay_samples 決定 pool 佈局(陣列實例另有 n_mics、capture_proxy_channel、max_delay_ms 與 residual);改了要重新查大小並重建。aec_create／aec_init 會複製一份設定,事後改手上那份無效,也不要改 aec.cfg。
mic／ref 前提ref 是實際送往喇叭的訊號,與 mic 同取樣率同時鐘;延遲只能是正的(mic 落後 ref)。函式庫不補償 clock drift。
延遲三態MATCHED(預設,線上估計)／FIXED(給量測延遲 fixed_delay_samples)／EXTERNAL_ALIGNED(呼叫端保證已對齊);非法組合在建立時被拒絕,不會被修正。表見 AEC API §4。
執行緒一個實例不是 thread-safe;aec_process*、aec_set_level、aec_reset、aec_apply_external_realign、aec_destroy 都要由呼叫端序列化。不同實例彼此獨立。
aec_reset清延遲估計、參考環、濾波器、偵測器、輸出 OLA 等執行期狀態,保留設定、記憶體與 aec_set_level 設的目標;會讓 generation 與 aec_post_reset_serial() 各 +1(aec_reset 是獨立的一次呼叫,不在任何處理呼叫之內,回傳時 serial 已是 +1 後的值;函式庫自己清 OLA 並把 CNG 種子設回 AEC_CNG_SEED;函式庫外自行合成的消費端看到 serial 改變就同步清自己的 OLA 與 CNG,不要反過來呼叫 aec_reset)。每個獨立串流前呼叫;只是外部對齊改變時改用 aec_apply_external_realign(不重啟 OLA,輸出連續)。
aec_destroyheap 實例釋放單一 arena,剛好一次;pool 實例不釋放任何記憶體(只清內部參考)、可重複呼叫(NULL 也安全),池由呼叫端回收。
零 heappool 路徑從 init 到 destroy 不呼叫 malloc(make test-zero-heap:50 個 init/process/reset/destroy 週期 allocator 呼叫為 0)。heap 路徑只在 aec_create 做一次 16-byte 對齊配置。

各函式對 NULL 的行為(會 crash／安全／no-op)的完整表在 AEC/docs/reference/lifecycle.md §5。

5. 接到 NR 與合成(單聲道整鏈)

AEC 庫本身不包 NR 或合成。整合者各自初始化 Aec、AnrDenoiser(NR 庫)、AcIstft(audiolib),並自己寫一小段每 hop 的串接;Audio_ALG 的 pipelines/mono/aec_nr_res/main.c 就是這樣(串接函式 mono_form())。AEC 端用預設的 residual = FULL 建立並以 aec_process_linear + aec_process_residual 驅動,單聲道的 RES 增益是 AEC 自己算的 rv.res_gain(由 aec_get_residual() 取得),不需另建 AecRes。

aec_process_linear(aec, mic, ref);           /* 線性 stage */
aec_process_residual(aec, NULL);             /* post 區塊,不寫 out、不套增益 */
AecResidualView rv = { .struct_size = sizeof rv };
aec_get_residual(aec, &rv);                  /* error_spec(E,分析用)、r2、comfort_noise、res_gain、base_spec:渲染底座(輸出守衛已套用)(借用 AEC 的 buffer) */
if (aec_post_reset_serial(aec) != my_serial) {   /* 硬 post 鏈 reset:在 ac_istft_push 之前(函式庫自己重設實例內 CNG 產生器) */
    ac_istft_reset(istft); my_serial = aec_post_reset_serial(aec);
}
const float *extra = NULL;
if (use_r2 && rv.r2 && rv.usable_linear) {          /* R2 併入噪音底,僅在 usable_linear 為真時 */
    sk_scale_f32(scratch, rv.r2, 1.0f / (32768.0f * 32768.0f), n_freqs);   /* r2 是 int16² 尺度 */
    extra = scratch;
}
g_nr = anr_process_gain_with_residual_psd(nr, rv.error_spec, extra);   /* NR 增益;extra 為 NULL 時等同 anr_process_gain(nr, rv.error_spec) */
aec_apply_gain(aec, g_nr, spec);                               /* P = base_spec * min(g_nr, g_res)(渲染 base_spec,不是 error_spec) */
if (use_cng) aec_apply_cng(aec, g_nr, spec);                   /* 開 CNG 時:實例內產生器,下限 AEC_CNG_NR_GAIN_FLOOR */
ac_istft_push(istft, spec, out);                               /* 反 FFT + 合成 + OLA */

上列 anr_* 屬 NR 庫,sk_*／ac_istft_push 屬 audiolib,只有 aec_* 是 AEC 庫的 API;流程時序見 aec_sequence §3,各 stage 的介面見 串接範例。
