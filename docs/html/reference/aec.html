AEC C library(單聲道實例的訊號流程)— AEC/c_impl

概要

本頁描述單聲道實例(AecConfig.n_mics = 1)的處理鏈與 state;四麥克風陣列實例(n_mics = 4,四條各自走這條線性鏈的 lane、共用 delay 估計器、融合與一次 G_res)見 AEC API §5a 與 aec_sequence §6a。

單聲道 PBFDKF 回音消除器的 float32 C 實作(Python aec.py 為演算法規格)。一個 hop 的處理鏈:mic 端 HPF → 飽和偵測 → AEC3 matched-filter 延遲估計 + 參考訊號 ring buffer 對齊 → PBFDAF shadow / PBFDKF main 線性濾波 → AEC3 post(殘留回音抑制 RES + CNG)。全部 state 收在單一 Aec struct(caller pool 或單一 heap arena),process 熱路徑零 malloc(make test-zero-heap 實測 50 個 init/process/reset/destroy 週期 allocator 呼叫為 0)。heap 與 caller-pool 兩條建構路徑輸出逐位元相同(test_static_aec 驗證 byte-equal)。

沒有任何 NN/NPU 成分:本函式庫是純 DSP,跨 hop 的 state 全部由 C struct 保存,host 不需另存任何 state。AecResidualView / AecLinearView 兩個 seam(aec_get_residual()／aec_get_linear(),搭配 aec_process_linear() + aec_process_residual())是外接 NN 後級(RES/NR)時的接點,見 AEC/docs/nn_integration_interface.md。

延遲為脈衝實測(AEC/docs/c_user_manual_zh_TW.md §3「演算法延遲(實測)」),無 look-ahead。搜尋範圍是編譯期常數(matched filter 搜尋長度 × 4 倍降取樣),環形緩衝大小不會提高它;48 kHz 內部先降到 16 kHz 估計再 ×3 回傳。單聲道 MATCHED 實際能回報的最大延遲是 delay_aec_max_delay_samples()(n = 5 時 8,148 sample,make test-delay-num-filters 釘住):8 kHz 約 1,018 ms,16 kHz 與 48 kHz 約 509 ms;參考環就是這個值加 hop_size,所以環不會成為額外的限制。另注意 aec.h 寫的 ~509 ms 是「可靠峰值」定義、608 ms 是幾何全跨度——兩種定義,非矛盾(見 nn_integration_interface.md)。delay estimator(matched filter)本身的機制/語意/語料延遲統計詳見 AEC/docs/delay_estimator_design_zh_TW.md。delay_num_filters config(Python+C,n=1..5,預設 5=行為不變)可依場景縮小 matched filter 算力:可靠搜尋上限 125/221/317/413/509 ms 對應 n=1..5,內部的分析週期預設 0(每 hop 全速分析)時每少一組省 ~4.2 MMAC/s 的搜尋算力(舊版量測,未重測),且 estimator 固定省 5,120 B/filter(四個格點都一樣);單通道 MATCHED 的參考環另縮短,合計每 filter 省 11,264 B(16／8 kHz)／23,552 B(48 kHz),見 AEC API §4「Delay mode」;僅在系統延遲已由 fixed_delay_samples 補償的部署縮小,bench/dataset 維持 5。

Warm-up(內部調校值,呼叫端不能設定):warmup_frames=100(10 ms 基準著作 ≈1000 ms;於 aec_carve() 對實際 hop 重定時,例如 16k/256 內部變 125 hop)期間濾波器以較積極方式收斂。延遲估計需 delay_aec_n_updates() ≥ 3 且 solid 才擷取;delay_est_period_s > 0 時,估計穩定 delay_est_init_s=0.3 秒後 duty-cycle 把 matched-filter 分析降到 1-in-K(ERLE 看門狗回退);預設 0.0 = 每 hop 全速分析。delay_acquire_warm_transfer=1(預設)在首次擷取時平移已學到的 IR 而非歸零,避免開場「垂直線」回音。
