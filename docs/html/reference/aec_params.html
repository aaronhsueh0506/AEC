AEC 外部參數與公開函式 — aec.h／aec_res.h

概要

外部＝第三方整合者可以安心調整的參數與函式;內部＝程式碼裡存在、也能改,但不建議開放(見 內部參數)。AecConfig 共 56 個欄位(aec.h:69-166):外部 11(其中 3 個經由 level 一次設定)、進階外部 4、整合者專用 2、deprecated 1、內部 38。建議用法:aec_config_from_level() 取得完整設定,只覆寫下表欄位。每列都附出處(aec.h:行 為欄位宣告,aec.c:行 為預設值或驗證);預設值用本機建置的 aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, 16000) 逐欄印出核對。各欄位「調了會怎樣」的效果說明見 參數效果。

除 level 的三個 floor 外,下表所有欄位都是「建立時決定」。改了必須 aec_destroy 後重建,或重新 aec_get_mem_size() + aec_init()。aec_create()／aec_init() 複製設定,事後改手上那份無效,也不要改 aec.cfg。

6. 驗證規則(被拒絕的設定)

驗證在 aec_create／aec_get_mem_size／aec_get_mem_breakdown／aec_init 內都會先跑(aec.c:236-347);任一欄位不合法整組拒絕(create → -1、get_mem_size → 0、init → NULL)。aec_validate_config 是 static,外部拿不到失敗原因。

類別規則
格點(sample_rate, fft_size) 必須是 8k/256、16k/256、16k/512、48k/1024 之一;fft_size = 0 拒絕
濾波器filter_length 1–4096;n_partitions 為 0 或 1–256
布林所有開關欄位必須是 0 或 1(含 enable_delay_est)
延遲模式MATCHED:fixed = -1;FIXED:fixed >= 0 且 <= 120 x sr、delay_num_filters = 5;EXTERNAL_ALIGNED:fixed = -1、delay_num_filters = 5;delay_num_filters 1–5
context seamspatial_linear_context 0–2;非 0 時必須 enable_res = 0 && return_res_context = 1
浮點必須有限且在範圍內(mu [0,10]、delta [0,1]、floor dB [-300,50]…)
validator 不做的事:沒有跨欄位檢查(filter_misadjustment_scale_min > scale_max 會被接受);範圍只防「崩壞」不防「音質崩壞」(mu = 10、floor +20 dB 都會被接受)。這也是內部欄位不宜開放的理由。

7. 擁有權、對齊與呼叫契約

  • 輸入 float32、標稱 [-1, 1];每次呼叫恰好 aec_hop_size() 個樣本,無長度參數。不做 clock drift 補償、不處理負延遲、不做 peak limiting(out 可能略超出 [-1, 1])。
  • 單一實例非 thread-safe;不同實例彼此獨立。AecResContext／AecLinearContext 的指標在下一次 process／reset 後失效,不可修改、不可 free。
  • NULL 行為:aec_create／aec_get_mem_size／aec_init／aec_destroy／aec_linear_is_cancelling／aec_set_level／aec_get_mem_breakdown 安全;aec_reset、aec_process、aec_process_context、aec_hop_size、aec_far_fft_real_compute_count 會 crash;aec_get_res_context／aec_get_linear_context／aec_debug_status 靜默 no-op。
  • pool 大小(本機 NE10 後端、balanced、MATCHED n = 5、aec_get_mem_size):8k/256 268,992 B;16k/256 366,000 B;16k/512 494,720 B;48k/1024 1,162,736 B。調整量(16k/256):enable_shadow = 0 -42,880 B;delay_num_filters 5→1 -22,912 B;EXTERNAL_ALIGNED -165,008 B;FIXED 1600 -158,096 B;live_observer_enabled = 1 +38,768 B;enable_res／enable_cng 不影響。絕對值隨 sizeof(Aec)／sizeof(AecConfig)(本機 224 B)整批移動,一律以 aec_get_mem_size() 為準。
  • 建置:同時連結 libaudio_common.a 與 -lm;-ffp-contract=off 必須;SIMD=0 與 SIMD=1 的輸出不保證逐位元相同,同一組旗標下 heap 與 pool 才保證相同(test_static_aec)。

8.2 前端 HPF

欄位預設範圍效果
enable_highpass10 或 1只作用於 mic 路徑。關掉時 highpass_cutoff_hz 完全惰性,連 pool 都不佔

8.3 輸入電平 / gain

AEC 的 AecConfig 沒有任何 gain 欄位。輸入電平調整屬於 AEC 之前的前級,由整合端負責:

Audio_ALG 沒有現成的 gain 模組：整合端自行在餵進 AEC 之前乘上固定增益，需要時自己加 clip。

電平會直接改變 AEC 行為:saturation_threshold(預設 0.95)判定 clipping、saturation_softclip_ref(預設 1)會對參考訊號做 soft-clip 以貼近實際被 clip 的喇叭輸出。把輸入 gain 調到讓 ref 常態接近滿刻度,會讓線性模型失準、ERLE 下降。詳見 audiolib API。
