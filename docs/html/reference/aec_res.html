AEC RES 增益階段與舒適噪音 — aec_apply_cng_spec()

1. 概要

Aec 內部的 post chain 會算出一組逐 bin 的殘留回音抑制增益 Gres(f)。這個增益階段沒有獨立的公開 API:單聲道的 Gres 在 Aec 裡(aec_get_residual().res_gain,強度用 aec_set_level()),四麥克風陣列實例(AecConfig.n_mics = 4)則在實例的記憶池內對融合後的頻譜算一次 Gres(aec_process_residual(),同樣用 aec_get_residual().res_gain 讀、aec_set_level() 設強度,見 aec_usage)。階段本身是庫內部模組 src/aec_res.c(標頭 src/aec_res_internal.h,不安裝)。

公開的只有與它搭配的舒適噪音填補 aec_apply_cng_spec()(宣告在 aec.h):aec_apply_cng() 的明確陣列形式,供自己持有產生器狀態的外部合成使用;底層的 aec_cng_fill()(可自選 nr_floor)在內部標頭 aec_internal.h。

2. 舒適噪音 API

#include "aec.h"

/* spec: the gain-weighted spectrum the caller is about to synthesize; cn: comfort_noise PSD (int16^2);
 * g_res: the G_res of this hop; g_nr: a denoiser gain or NULL; rng: the caller's generator, started at AEC_CNG_SEED. */
void add_comfort_noise(uint32_t *rng, Complex *spec, const float *cn, const float *g_res,
                       const float *g_nr, int n_bins)
{
    aec_apply_cng_spec(rng, spec, cn, g_res, g_nr, n_bins);
}
函式語意回傳
aec_apply_cng_spec(&rng, spec, cn, g_res, g_nr, n)在 bin 1…n−2 加上舒適噪音,見 §3;g_nr(宣告中的 g_extra)可為 NULL,nr_floor 固定為 AEC_CNG_NR_GAIN_FLOORvoid;任一必要指標為 NULL 或 n<3 則什麼都不動
aec_apply_cng(a, extra_gain, spec)實例形式:用實例內的產生器(種子 AEC_CNG_SEED,硬 post 鏈 reset 時重設)AEC_OK／AEC_ERR_*

2.2 4ch 應用:陣列實例

四條 lane、共用 delay 估計器與融合階段都在同一個 Aec 實例內(AecConfig.n_mics = 4,residual = FULL;以 aec_get_mem_requirements() + aec_init_ex() 建立)。每 hop:aec_process_linear() → 呼叫端的 SRP／beamformer 讀 aec_get_array() → aec_process_residual()(帶權重與波束成形後頻譜)→ aec_get_residual() → 呼叫端的 NR 增益 → aec_apply_gain() → aec_apply_cng() → 合成。融合時的增益階段輸入(E、Y、R²、N²、對齊後 far、all_converged／max_dt／max_saturation／clock_drift)由實例自己彙整,呼叫端不組 AecResInput。

3. Block diagram

RES 增益階段(內部 aec_res_process,每 hop 一次)
 ├─ 近端功率   P[k] = |near[k]|^2                       (all_converged: min(|error[k]|^2, |near[k]|^2))
 │             P[k] *= 32768^2                            → int16^2 尺度
 ├─ 參考       ref[i] = render_hop[i] * 32768
 ├─ 旗標       initial_state && all_converged → 離開初始狀態
 │             dt_protect = (max_dt > 0.2);  saturated = (max_saturation > 0.5)
 └─ suppression_gain_get_gain(P, r2, r2, comfort_noise, ref, clock_drift, saturated)
        → g_res[k]  (SuppressionGain 內部:ENR/EMR、audibility、DominantNearend、地板、ratchet)

aec_cng_fill(&rng, spec, cn, g_res, g_nr, floor, n)         k = 1 … n−2
 ├─ amp = sqrt(cn[k]/32768^2) * sqrt(1 − g_res[k]^2) * max(g_nr[k], floor)
 ├─ rng = (rng*69069 + 1) & 0x7FFFFFFF;  ix = rng >> 26
 └─ spec[k] += amp * (LUT[ix], LUT[(ix+8)&31])          LUT = sqrt(2)·sin(2πi/32)

7. 延遲與 warm-up

無演算法延遲(同 hop 內回傳)。實例以 initial_state = 1 起始:初始階段是否啟用 DominantNearend 觸發與低頻平滑,由設定中的 dne_use_during_initial_phase／lf_smoothing_during_initial_phase 決定;第一次 all_converged 為真的 hop 離開初始狀態,之後不會回去,直到 aec_reset()。設定來自 AecConfig 的共同建構函式,其中這兩個旗標固定為 1,所以經由本介面,初始狀態對增益沒有影響;離開初始狀態的判斷與狀態仍保留,供旗標被關閉的設定使用。

8. 與 Aec 內部舒適噪音的關係

aec_cng_fill(aec_internal.h)是 Aec 內部輸出階段(aec_post_apply_output())與外部合成共用的唯一舒適噪音實作:每個分量加 ng · (nf · 表值),nf = sqrt(max(cn/32768², 0))、ng = sqrt(max(1−g_res², 0))(有 g_nr 時再乘 max(g_nr, nr_floor)),每個 bin 一步 LCG、依 bin 由小到大、bin 0 與 n−1 不抽樣。g_nr == NULL 時,公開呼叫與 aec_process() 內部的舒適噪音在相同輸入下逐位元相同(內部以全增益當 g_res)。
