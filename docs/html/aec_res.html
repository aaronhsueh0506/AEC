AEC RES 級 — aec_res.h

1. 概要

Aec 內部的 post chain 會算出一組逐 bin 的殘留回音抑制增益 Gres(f)。多 lane 的整合(例如 4ch:四條線性 AEC → beamform／融合 → 一個共用的 RES)需要的是「對融合後的頻譜算一次 Gres」,而不是每條 lane 各算一次。aec_res.h 把同一個抑制器獨立出來,並附上與它搭配的舒適噪音填補 aec_cng_fill()。

  • 設定來自與 lane 相同的建構函式(aec_build_sg_config),所以由同一個 AecConfig 建出的 AecRes 與 lane 內的抑制器設定逐位元相同。
  • Static memory:呼叫端給一塊 16-byte 對齊的記憶體;process／reset／set_preset 不配置記憶體、不用 stdio、無全域狀態。
  • 只有 sample_rate、fft_size、min_gain_floor_far_active_db、min_gain_floor_dt_db 會影響抑制器;其餘 AecConfig 欄位僅參與驗證。

2. API 用法

#include "aec_res.h"

AecConfig cfg;
aec_config_from_preset(&cfg, AEC_PRESET_BALANCED, 16000);   /* fft_size 256 */

size_t bytes = aec_res_get_mem_size(&cfg);                 /* 0 = cfg 無效 */
void*  mem   = /* 16-byte 對齊、至少 bytes */;
AecRes* res  = aec_res_init(mem, bytes, &cfg);             /* NULL = 失敗 */

AecResInput in = {0};
in.error_spec = fused_error;  in.near_spec = fused_near;     /* audio 尺度 */
in.r2 = fused_r2;  in.comfort_noise = fused_comfort;         /* int16^2 尺度 */
in.render_hop = aligned_ref;                                 /* hop_size 個樣本 */
in.all_converged = all_lanes_converged;
in.max_dt = worst_dt_indicator;  in.max_saturation = worst_saturation;
in.clock_drift = drift_flag;

const float* g_res = aec_res_process(res, &in);            /* n_bins 個增益,[0,1] */
/* ... g = min(g_nr, g_res); spec = error_spec * g ... */
aec_cng_fill(&rng, spec, fused_comfort, g_res, g_nr, 0.31622777f, aec_res_n_bins(res));

aec_res_set_preset(res, AEC_PRESET_AGGRESSIVE, 100.0f);     /* hop 之間呼叫 */
aec_res_reset(res);                                          /* stream 邊界 */
函式語意回傳
aec_res_get_mem_size(cfg)所需 byte 數0 = cfg 為 NULL／無效
aec_res_init(mem, bytes, cfg)在 mem 內建立實例;不需 destroyNULL = 記憶體 NULL／未對齊／過小，或 cfg 無效
aec_res_reset(r)清除抑制器全部狀態;保留目前的 far-active 地板目標(含 set_preset 改過的)void;NULL 安全
aec_res_process(r, in)一個 hop。回傳的指標由 r 擁有,到下一次對 r 的呼叫前有效NULL = r／in 為 NULL 或任一輸入陣列為 NULL
aec_res_set_preset(r, preset, ramp_ms)與 aec_set_preset() 同語意:改 far-active 地板(ramp_ms==0 於下一 hop 生效,上限 60 s)與 DT 地板(aggressive 才跟其他兩個不同;無 ramp,立即套用)0／−1(NULL、非法 preset、ramp 超範圍;−1 時什麼都不寫)
aec_res_split_floor(r, &live, &target)far-active 地板的功率比:live = 現行值,target = 正在走向的值0／−1(r 為 NULL)
aec_res_n_bins(r)、aec_res_hop_size(r)陣列長度0 = NULL
aec_cng_fill(&rng, spec, cn, g_res, g_nr, nr_floor, n)在 bin 1…n−2 加上舒適噪音,見 §3void;任一必要指標為 NULL 或 n<3 則什麼都不動

3. Block diagram

aec_res_process(r, in)
 ├─ 近端功率   P[k] = |near[k]|^2                       (all_converged: min(|error[k]|^2, |near[k]|^2))
 │             P[k] *= 32768^2                            → int16^2 尺度
 ├─ 參考       ref[i] = render_hop[i] * 32768
 ├─ 旗標       initial_state && all_converged → 離開初始狀態
 │             dt_protect = (max_dt > 0.2);  saturated = (max_saturation > 0.5)
 └─ suppression_gain_get_gain(P, r2, r2, comfort_noise, ref, clock_drift, saturated)
        → g_res[k]  (SuppressionGain 內部:ENR/EMR、audibility、DominantNearend、地板、ratchet)

aec_cng_fill(&rng, spec, cn, g_res, g_nr, floor, n)         k = 1 … n−2
 ├─ amp = sqrt(cn[k]/32768^2) * sqrt(1 − g_res[k]^2) * max(g_nr[k], floor)
 ├─ rng = (rng*69069 + 1) & 0x7FFFFFFF;  ix = rng >> 26
 └─ spec[k] += amp * (LUT[ix], LUT[(ix+8)&31])          LUT = sqrt(2)·sin(2πi/32)

hop t          caller / 融合級                 aec_res                         caller / NR + 合成
─────────────────────────────────────────────────────────────────────────────────────────
t              各 lane 線性 AEC 完成
               融合 E, Y, R^2, N^2
               ───────── AecResInput ───────▶ aec_res_process
                                               (同一 hop 內完成,無延遲)
                                      ◀──── g_res (n_bins) ────

                                                                      IFFT / OLA → 輸出 hop

error_specComplex[n_bins]audio([−1,1] 時域)error_spec,或多 lane 融合後的對應量
near_specComplex[n_bins]audionear_spec 的融合
r2float[n_bins]int16² 功率r2;同時當作 bounded 與 unbounded 估計
comfort_noisefloat[n_bins]int16² 功率comfort_noise
render_hopfloat[hop_size]audio 時域已對齊的遠端參考
all_converged／max_dt／max_saturation／clock_driftint／float／float／int—各 lane 的 filter_converged／dt_indicator／saturation_level、延遲估計器的 clock-drift 旗標
輸出const float[n_bins]振幅 [0,1]等同 AecResContext.res_gain

n_bins = fft_size/2 + 1,hop_size = fft_size/2。16k/256 → 129 bin／128;16k/512 → 257／256;48k/1024 → 513／512;8k/256(舊格點)→ 129／128。

7. 延遲與 warm-up

無演算法延遲(同 hop 內回傳)。實例以 initial_state = 1 起始:初始階段是否啟用 DominantNearend 觸發與低頻平滑,由設定中的 dne_use_during_initial_phase／lf_smoothing_during_initial_phase 決定;第一次 all_converged 為真的 hop 離開初始狀態,之後不會回去,直到 aec_res_reset()。設定來自 AecConfig 的共同建構函式,其中這兩個旗標固定為 1,所以經由本介面,初始狀態對增益沒有影響;離開初始狀態的判斷與狀態仍保留,供旗標被關閉的設定使用。

8. 多 lane pipeline 原本向 AEC 內部取用的符號

4ch pipeline(Audio_ALG/pipelines/4ch_aec_bf_nr_res/4aec_nr_res.c)目前自己 include 內部 header 重做這一級。對應如下;「已提供」表示 aec_res.h 能取代,pipeline 端改接線是另一項工作。

pipeline 現在用的用途取代者
lanes[0]->a3_sg.cfg／.tun取得抑制器設定aec_res_init(mem, bytes, &aec_cfg)
SuppressionGain／Config／Tuning、suppression_gain_init建立與 reset 抑制器aec_res_init／aec_res_reset
suppression_gain_set_initial_state、.initial_state、.dt_protect_active、suppression_gain_get_gainpost_res_gainaec_res_process(閾值 0.2／0.5 固定於內部)
suppression_gain_set_split_floor_far_active_db、.cfg.split_floor_far_activepreset 改強度(ramp)aec_res_set_preset
.split_floor_far_active_live、post_sg_cfg.split_floor_far_active診斷:現行／目標地板aec_res_split_floor
AEC3B_SQRT2_SIN_LUT(aec3_balanced_config.h)舒適噪音填補aec_cng_fill
delay_aec3_*(delay_aec3.h)共用延遲估計器仍是內部符號,不在 RES 級範圍內,本介面不提供
aec_cng_fill 與 Aec 自己的舒適噪音(aec3_post.c)同配方、不同算式:同一個亂數遞推與查表,但本函式用 libm 的 sqrtf／除法,與兩條 pipeline 的迴圈逐位元相同;Aec 內部則是批次化的 inv_psd_scale＋sk_fast_sqrt_f32。兩者不要混用在要求位元一致的比對中。
