AEC RES 級 — aec_res.h

1. 概要

Aec 內部的 post chain 會算出一組逐 bin 的殘留回音抑制增益 Gres(f)。多 lane 的整合(例如 4ch:四條線性 AEC → beamform／融合 → 一個共用的 RES)需要的是「對融合後的頻譜算一次 Gres」,而不是每條 lane 各算一次。aec_res.h 把同一個抑制器獨立出來,並附上與它搭配的舒適噪音填補 aec_cng_fill()。

誰持有 RES:單聲道的 RES 就在 Aec 裡面(增益是 ctx.res_gain,強度用 aec_set_level(),由 aec_get_res_context() 取得),不需要另建 AecRes;單聲道是唯一的例外。Audio_ALG 的 4ch 流程層 mcab(pipelines/4ch_aec_bf_nr_res/mcab.h)不是 library:四條 Aec lane 與(MATCHED 時)共用的 DelayAec 由應用自己建立、以指標交給 mcab;mcab 只擁有 flow 狀態,並以 mcab_fuse() 把呼叫端波束成形權重投影出的 E、R²、CN 組成 McabFrame(g_res_ctx = NULL)。波束成形不在 mcab 內(sample 層 helper mcab_sample_beam.h 提供 SRP-PHAT＋BF 的接法),mcab 不持有、不建立、也不執行 RES。4ch 應用要 RES,就在自己的 init 裡用本頁的函式建一個 AecRes(設定來自 aec_config_from_level(level, sample_rate),fft_size 取 flow 的格點),每 hop 在 fuse 之後以 mcab_sample_res_input(&frame, &in)(pipelines/4ch_aec_bf_nr_res/mcab_sample_post.h)組出 AecResInput,再呼叫 aec_res_process(res, &in),強度用 aec_res_set_level(),串流邊界用 aec_res_reset();做法見 §2.3。範例:4ch_aec_bf_nr_res/mcab_static.c、mcab_raw.c、mcab_external_static.c,以及 pipelines/dfn/4ch_aec_bf_dfn_res/main.c;pipelines/ulcnet/4ch_alignulcnet 以 cfg.enable_post = 0 跑 flow、不接 RES。

  • 設定來自與 lane 相同的建構函式(aec_build_sg_config),所以由同一個 AecConfig 建出的 AecRes 與 lane 內的抑制器設定逐位元相同。
  • Static memory:呼叫端給一塊 16-byte 對齊的記憶體;process／reset／set_level 不配置記憶體、不用 stdio、無全域狀態。
  • 只有 sample_rate、fft_size、min_gain_floor_far_active_db、min_gain_floor_dt_db 與 min_gain_split_floor_enabled(aec.c:995-1000,讓 NO_FLOOR 在建構時就生效)會影響抑制器;其餘 AecConfig 欄位僅參與驗證(傳入的 cfg 必須通過完整驗證,否則 aec_res_get_mem_size 回 0)。

2. API 用法

#include <stdlib.h>
#include "aec_res.h"

/* One hop of the standalone RES stage over spectra the caller has already fused. */
int res_one_hop(const AecConfig *cfg, const AecResInput *in, uint32_t *rng,
                Complex *spec, const float *g_nr)
{
    size_t bytes = aec_res_get_mem_size(cfg);         /* 0 = cfg invalid */
    void *mem = NULL;
    if (bytes == 0 || posix_memalign(&mem, 16, bytes) != 0) return -1;
    AecRes *res = aec_res_init(mem, bytes, cfg);      /* NULL = unaligned / too small / bad cfg */
    if (!res) { free(mem); return -1; }

    const float *g_res = aec_res_process(res, in);    /* n_bins gains in [0, 1], owned by res */
    if (g_res) {
        /* spec = error_spec * min(g_nr, g_res) is applied by the caller, then: */
        aec_cng_fill(rng, spec, in->comfort_noise, g_res, g_nr, 0.31622777f, aec_res_n_bins(res));
    }
    (void)aec_res_set_level(res, AEC_LEVEL_AGGRESSIVE, 100.0f);   /* between hops */
    aec_res_reset(res);                               /* stream boundary; no destroy exists */
    free(mem);
    return g_res ? 0 : -1;
}

上列 res.c 已在暫存複本以 -Wall -Wextra -Werror 編譯並跑完一個 hop(in 的欄位由呼叫端填:error_spec／near_spec 為融合後的 audio 尺度頻譜,r2／comfort_noise 為 int16^2 尺度,render_hop 為 hop_size 個已對齊參考樣本,以及 all_converged／max_dt／max_saturation/clock_drift)。實務上 mem 在初始化時配置一次,aec_res_process 每 hop 呼叫;範例把整個生命週期壓進一個函式只為可編譯檢查。

函式語意回傳
aec_res_get_mem_size(cfg)所需 byte 數0 = cfg 為 NULL／無效
aec_res_init(mem, bytes, cfg)在 mem 內建立實例;不需 destroyNULL = 記憶體 NULL／未對齊／過小，或 cfg 無效
aec_res_reset(r)清除抑制器全部狀態;保留目前的 far-active 地板目標(含 set_level 改過的)void;NULL 安全
aec_res_process(r, in)一個 hop。回傳的指標由 r 擁有,到下一次對 r 的呼叫前有效NULL = r／in 為 NULL 或任一輸入陣列為 NULL
aec_res_set_level(r, level, ramp_ms)與 aec_set_level() 同語意:改 far-active 地板(ramp_ms==0 於下一 hop 生效,上限 60 s)與 DT 地板(aggressive 才跟其他兩個不同;無 ramp,立即套用)0／−1(NULL、非法 level、ramp 超範圍;−1 時什麼都不寫)

aec_res_n_bins(r)、aec_res_hop_size(r)陣列長度0 = NULL
aec_cng_fill(&rng, spec, cn, g_res, g_nr, nr_floor, n)在 bin 1…n−2 加上舒適噪音,見 §3void;任一必要指標為 NULL 或 n<3 則什麼都不動

2.3 4ch 應用:在 mcab flow 之後建立並使用 RES

四條 lane、共用 delay 估計器與 mcab 自己的 pool 由應用依 mcab.h 的順序建好(aec_get_mem_size()／delay_aec_get_mem_size()／mcab_get_mem_requirements()，mcab_static.c 的 unit_plan()／unit_init() 是一份完整寫法；mcab_sample_flow.h 的 mcab_sample_flow_init() 把這幾步放進一塊 pool)。RES 由應用接著建,pool 另外查大小(aec_res_get_mem_size())；mcab_static.c 把 RES 與 NR、合成、暫存向量併成另一塊 post pool 再依序切(post_plan(),aec_res_init 在 post pool 上)。呼叫順序:查大小 → 配置 → aec_res_init → 每 hop(front＋beam → fuse → aec_res_process)→ hop 之間 aec_res_set_level → 串流邊界或任一階段拒絕時 mcab_sample_beam_reset(或自帶 beamformer 時 mcab_reset)加 aec_res_reset。

#include <stdlib.h>
#include "4ch_aec_bf_nr_res/mcab_sample_beam.h"  /* mcab flow + sample SRP-PHAT/BF helper */
#include "aec_res.h"                              /* libaec: AecRes, aec_res_* */
#include "4ch_aec_bf_nr_res/mcab_sample_post.h"  /* mcab_sample_res_input() */

typedef struct App4ch {
    Mcab *flow;               /* built by the application: 4 lanes, estimator, mcab_init_ex() */
    McabSampleBeam *beam;     /* sample helper over the flow */
    AecRes *res;
    void *res_mem;
} App4ch;

/* Init, after the flow exists: the RES is the application's own object on the flow's grid. */
int app_res_init(App4ch *a, AecLevel level)
{
    AecConfig cfg;
    aec_config_from_level(&cfg, level, mcab_sample_rate(a->flow));
    cfg.fft_size = mcab_fft_size(a->flow);
    size_t bytes = aec_res_get_mem_size(&cfg);                 /* 0 = cfg invalid */
    if (bytes == 0 || posix_memalign(&a->res_mem, 16, bytes) != 0) return -1;
    a->res = aec_res_init(a->res_mem, bytes, &cfg);            /* no destroy exists */
    if (!a->res || aec_res_n_bins(a->res) != mcab_n_freqs(a->flow)) return -1;
    return 0;
}

/* One hop: front + beam -> fuse -> RES gain; NR, min(), CNG and synthesis follow in the application. */
int app_hop(App4ch *a, const float *mics, const float *ref, int vad, McabFrame *frame,
            const float **g_res)
{
    McabSampleBeamResult beam;
    McabSampleBeamInfo info;
    int st = mcab_sample_beam_process_with_activity(a->beam, mics, ref, 1, vad, NULL, &beam, &info);
    if (st == MCAB_OK) st = mcab_sample_beam_fuse(a->beam, frame);   /* frame->g_res_ctx stays NULL */
    if (st == MCAB_OK) {
        AecResInput in;
        mcab_sample_res_input(frame, &in);                           /* McabFrame -> AecResInput */
        *g_res = aec_res_process(a->res, &in);
        if (!*g_res) { mcab_sample_beam_reset(a->beam); st = MCAB_DSP_ERROR; }
    }
    if (st != MCAB_OK) aec_res_reset(a->res);   /* DSP_ERROR: the flow has reset itself; reset the rest */
    return st;
}

/* Between hops / at a stream boundary. */
int app_res_strength(App4ch *a, AecLevel level) { return aec_res_set_level(a->res, level, 100.0f); }
void app_reset(App4ch *a) { mcab_sample_beam_reset(a->beam); aec_res_reset(a->res); }

上列已在暫存複本以 clang -fsyntax-only -Wall -Wextra -Werror 對 mcab_sample_beam.h、mcab_sample_post.h、aec_res.h 檢查通過(只檢查語法、未連結；include 路徑以 pipelines/ 為根)。app_hop 之後的 NR 增益、min、CNG、合成見下方時序圖與 mcab_static.c 的 static_chain()。

3. Block diagram

aec_res_process(r, in)
 ├─ 近端功率   P[k] = |near[k]|^2                       (all_converged: min(|error[k]|^2, |near[k]|^2))
 │             P[k] *= 32768^2                            → int16^2 尺度
 ├─ 參考       ref[i] = render_hop[i] * 32768
 ├─ 旗標       initial_state && all_converged → 離開初始狀態
 │             dt_protect = (max_dt > 0.2);  saturated = (max_saturation > 0.5)
 └─ suppression_gain_get_gain(P, r2, r2, comfort_noise, ref, clock_drift, saturated)
        → g_res[k]  (SuppressionGain 內部:ENR/EMR、audibility、DominantNearend、地板、ratchet)

aec_cng_fill(&rng, spec, cn, g_res, g_nr, floor, n)         k = 1 … n−2
 ├─ amp = sqrt(cn[k]/32768^2) * sqrt(1 − g_res[k]^2) * max(g_nr[k], floor)
 ├─ rng = (rng*69069 + 1) & 0x7FFFFFFF;  ix = rng >> 26
 └─ spec[k] += amp * (LUT[ix], LUT[(ix+8)&31])          LUT = sqrt(2)·sin(2πi/32)

7. 延遲與 warm-up

無演算法延遲(同 hop 內回傳)。實例以 initial_state = 1 起始:初始階段是否啟用 DominantNearend 觸發與低頻平滑,由設定中的 dne_use_during_initial_phase／lf_smoothing_during_initial_phase 決定;第一次 all_converged 為真的 hop 離開初始狀態,之後不會回去,直到 aec_res_reset()。設定來自 AecConfig 的共同建構函式,其中這兩個旗標固定為 1,所以經由本介面,初始狀態對增益沒有影響;離開初始狀態的判斷與狀態仍保留,供旗標被關閉的設定使用。

8. 與 Aec 內部舒適噪音的差異

aec_cng_fill 與 Aec 自己的舒適噪音(aec_post.c)同配方、不同算式:同一個亂數遞推與查表,但本函式用 libm 的 sqrtf／除法,就是 Audio_ALG 範例(例如 pipelines/mono_aec_nr_res/main.c 的 mono_form())每個 hop 呼叫的那個函式;Aec 內部則是批次化的 inv_psd_scale＋sk_fast_sqrt_f32。兩者不要混用在要求位元一致的比對中。
