AEC · 回音消除

一支麥克風與一路播放參考，每 hop 消除回音；AecConfig.n_mics = 4 時是四麥克風陣列實例（四條線性 lane、共用 delay 估計器與融合，beamformer 與合成由呼叫端提供）。板端可取得線性殘差給後級模型，也可由 AEC 完成 RES 與合成。

先處理一段 WAV

將 audiolib/ 放在本庫旁邊，從 AEC 根目錄執行。

make -C c_impl
bin="$(make -s -C c_impl print-bin-dir)"
"$bin/aec_wav" mic.wav ref.wav out.wav --level 1

使用 Python 參考實作（單聲道孿生，以下不屬於 C 函式庫）

python3 python/aec.py mic.wav ref.wav out.wav --mode pbfdkf --preset balanced --enable-res

將 python/ 加入 PYTHONPATH 後，也可在 Python 程式中逐 hop 呼叫。

from aec import AEC, AecConfig, AecMode, AecPreset

cfg = AecConfig.from_preset(AecPreset.BALANCED, sample_rate=16000,
                            mode=AecMode.PBFDKF, enable_res=True)
aec = AEC(cfg)
for mic_hop, ref_hop in hop_pairs:
    output = aec.process(mic_hop, ref_hop)
