AEC · 單聲道回音消除

一支麥克風與一路播放參考，每 hop 消除回音。板端可取得線性殘差給後級模型，也可由 AEC 完成 RES 與合成。

先處理一段 WAV

將 audiolib/ 放在本庫旁邊，從 AEC 根目錄執行。

make -C c_impl
bin="$(make -s -C c_impl print-bin-dir)"
"$bin/aec_wav" mic.wav ref.wav out.wav --level balanced

使用 C 函式庫

初始化與逐 hop 呼叫
選擇 heap 或 caller pool，串接麥克風與播放參考。
API 與資料契約
查 grid、delay mode、三種輸出模式與診斷。
時序與 reset
查看第一個 hop、切流、延遲變更和錯誤路徑。

串接後級與調整音訊

獨立 RES 與舒適噪音
在共享或 beamformed 頻譜上取得增益並合成。
參數與強度
查設定範圍、HPF、level 與立即生效的控制。
訊號流程與延遲
追蹤線性殘差、渲染基底以及頻譜和 PCM 的延遲。

進階參考

內部參數
核對內部使用的設定、狀態與編譯選項。

使用 Python 參考實作

python3 python/aec.py mic.wav ref.wav out.wav --mode pbfdkf --preset balanced --enable-res

將 python/ 加入 PYTHONPATH 後，也可在 Python 程式中逐 hop 呼叫。

from aec import AEC, AecConfig, AecMode, AecPreset

cfg = AecConfig.from_preset(AecPreset.BALANCED, sample_rate=16000,
                            mode=AecMode.PBFDKF, enable_res=True)
aec = AEC(cfg)
for mic_hop, ref_hop in hop_pairs:
    output = aec.process(mic_hop, ref_hop)
