8.1 抑制強度 — 三個 preset 只差一個欄位

Presetmin_gain_floor_far_active_db效果
AEC_PRESET_MILD−20.0遠端單講時 echo 壓得最淺,近端被誤削的風險最低
AEC_PRESET_BALANCED−28.0(預設)—
AEC_PRESET_AGGRESSIVE−38.0echo 壓最深,近端被誤削風險最高

合法範圍 [-300, 50]。可用 aec_preset_floor_db() 純查表(不需要 instance),或用 aec_set_preset() 執行期改(§9)。

量測前務必知道:這個地板只在 far-active 且非 double-talk 的 hop 咬得到。DT 期間走的是 min_gain_floor_dt_db(−16 dB,三個 preset 完全相同);far-active latch 觸發前用的是 far-silent 地板。而且同一個 gain 也決定 comfort noise 的量 → 只量 echo／degradation 的 A/B 會把 CNG 的變化錯記到別的機制。請在 echo 對齊或 degradation 對齊的條件下比較,並實際試聽。

8.2 前端 HPF

欄位預設範圍效果
enable_highpass10 或 1只作用於 mic 路徑。關掉時 highpass_cutoff_hz 完全惰性,連 pool 都不佔
highpass_cutoff_hz80.0啟用時:finite、>0、< 0.45 × sample_rate(16k → 上限 7200 Hz)切掉 mic 的 DC／rumble。調高(如 150 Hz)→ 風噪、桌面震動更乾淨,但男聲基頻可能被削
far(ref)路徑沒有 HPF,連實例都不存在——整個 lib 只有一個 hp_mic。這是刻意的設定,不要試圖用 config 打開 far HPF。若 ref 需要 HPF,請在餵進 AEC 之前用 audio_common 的 hpf.h 自己做,但先確認你真的需要。

8.3 輸入電平 / gain

AEC 的 AecConfig 沒有任何 gain 欄位。輸入電平調整屬於 AEC 之前的前級,由 audio_common 或 pipeline 層負責:

模組位置特性
AudioPreGainaudio_common/include/audio_pre_gain.hmono、振幅 dB(10^(db/20))、不做 clipping、有 runtime audio_pre_gain_set_db()
FixGainAudio_ALG/pipelines/third_party/gain/fix_gain.h多聲道、per-channel gain + 選配 clip、沒有 retune 路徑(改值要重建 instance)
電平會直接改變 AEC 行為:saturation_threshold(預設 0.95)判定 clipping、saturation_softclip_ref(預設 1)會對參考訊號做 soft-clip 以貼近實際被 clip 的喇叭輸出。把 pre-gain 調到讓 ref 常態接近滿刻度,會讓線性模型失準、ERLE 下降。詳見 audio_common API。
