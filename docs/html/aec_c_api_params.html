8.1 抑制強度 — mild/balanced 只差一個欄位,aggressive 差兩個

Levelmin_gain_floor_far_active_dbmin_gain_floor_dt_db效果
AEC_LEVEL_MILD−20.0−20.0遠端單講時 echo 壓得最淺,近端被誤削的風險最低
AEC_LEVEL_BALANCED−28.0(預設)−20.0(預設)—
AEC_LEVEL_AGGRESSIVE−38.0−30.0echo 壓最深,近端被誤削風險最高;DT 地板也跟著深化,否則 double-talk 觸發時三個 level 會蓋回同一個 −20.0,聽不出差異

合法範圍 [-300, 50]。可用 aec_level_floor_db() / aec_level_dt_floor_db() 純查表(不需要 instance),或用 aec_set_level() 執行期改(§9)。

量測前務必知道:far-active 地板只在 far-active 且非 double-talk 的 hop 咬得到。DT 期間走的是 min_gain_floor_dt_db(mild/balanced 共用 −20 dB,aggressive 是 −30 dB);far-active latch 觸發前用的是 far-silent 地板。而且同一個 gain 也決定 comfort noise 的量 → 只量 echo／degradation 的 A/B 會把 CNG 的變化錯記到別的機制。請在 echo 對齊或 degradation 對齊的條件下比較,並實際試聽。

8.2 前端 HPF

欄位預設範圍效果
enable_highpass10 或 1只作用於 mic 路徑。關掉時 highpass_cutoff_hz 完全惰性,連 pool 都不佔
highpass_cutoff_hz80.0啟用時:finite、>0、< 0.45 × sample_rate(16k → 上限 7200 Hz)切掉 mic 的 DC／rumble。調高(如 150 Hz)→ 風噪、桌面震動更乾淨,但男聲基頻可能被削
far(ref)路徑沒有 HPF,連實例都不存在——整個 lib 只有一個 hp_mic。這是刻意的設定,不要試圖用 config 打開 far HPF。若 ref 需要 HPF,請在餵進 AEC 之前用 audiolib 的 hpf.h 自己做,但先確認你真的需要。

8.3 輸入電平 / gain

AEC 的 AecConfig 沒有任何 gain 欄位。輸入電平調整屬於 AEC 之前的前級,由整合端負責:

Audio_ALG 沒有現成的 gain 模組：整合端自行在餵進 AEC 之前乘上固定增益，需要時自己加 clip。

電平會直接改變 AEC 行為:saturation_threshold(預設 0.95)判定 clipping、saturation_softclip_ref(預設 1)會對參考訊號做 soft-clip 以貼近實際被 clip 的喇叭輸出。把輸入 gain 調到讓 ref 常態接近滿刻度,會讓線性模型失準、ERLE 下降。詳見 audiolib API。

n_partitions0(= 由 filter_length 推導)0 或 1..256直接覆寫 partition 數,實際 tap span = n_partitions × hop

kalman_q_high / _low1e-3 / 1e-6[0,1]未收斂 / 收斂後的 process noise。high 大 → 追蹤快;low 小 → 穩態 misadjustment 低
enable_shadow10/1關掉會同時失去 shadow-based double-talk 偵測與 echo-path-change 偵測,且 pool 變小
warmup_frames100 hops(1000 ms)[0,1e6]暖機期間 mu 不受 converged 壓制。以 hop 計,會 retime

dt_aware_res_floor_enabled10/1啟用 DT 專用地板

ne_recent_threshold0.3[0,1000]超過才算「近端剛出現」。只讀 energy DT；遠端單講時通常很低，但 loud residual echo 仍可能誤觸，這也是 DT floor 不能無限制調淺的原因。
ne_recent_hold150 hops(1500 ms)[0,1e6]觸發後 hold 多久。會 retime
ne_recent_sustain3[0,1e6]需連續幾 hop 超門檻才 arm。每 hop 必定遞增或歸零,其實是時長、不是真的事件計數;但三個格點目前各自已驗證的「3 hop」對應三種不同時長,換算成單一時長會讓 16kHz/512 格點新增回音誤觸發,故仍刻意不 retime
dt_aware_recovery_soft10/1近端剛出現時走軟性 realign,避免 DT 中把濾波器打掉
飽和 / CNG
enable_saturation10/1建構 ref/mic 飽和偵測器
saturation_threshold0.95[0,10]判定 clipping 的振幅門檻。偵測到會讓 AEC3 進保守模式
saturation_softclip_ref10/1對 ref 做 soft-clip 以貼近被 clip 的喇叭輸出 → 改善大音量下的 ERLE
enable_cng10/1深度抑制段落注入舒適噪音。關掉 → 聽起來「抽真空」。只有 enable_res==1 時才有效
Delay 取得行為(僅 MATCHED)
max_delay_ms / delay_buffer_ms1024 / 2048[0,60000]／[0,120000]共同決定 search ring 大小,而 ring 大小同時是 estimate 的准入閘 → 改小會改變預設路徑的音訊
delay_est_init_s0.3[0,3600]進入 duty-cycle 省電抽樣前需連續穩定的秒數。調大 → 更晚省電
delay_est_period_s0.0[0,3600]matched filter 的分析週期(算力節流)。0 = 每個 hop 都分析(全速)；> 0 時,進入 duty-cycle 後每 K 個 hop 才實跑一次(K = round(period ÷ hop 時長) ÷ 5,下限 1)。調大 → 更省 MIPS,但 delay 變動偵測更慢
delay_acquire_protect_converged10/1已在消除時不做首次 realign。關掉 → 首鎖更積極,但可能打掉已收斂的濾波器
delay_acquire_warm_transfer10/1符合閘門時平移已學到的 IR 而非清零,避免 spectrogram 上的垂直線
