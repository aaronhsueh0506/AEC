AEC 內部參數 — 可以調,但不建議開放

概要

本頁列出 AecConfig 中不屬於 外部參數 的 38 個欄位,以及完全不在 AecConfig 裡、編譯期固定的常數。這些「在程式碼裡存在、技術上能改」,但不建議交給第三方:共同原因是它們是聯合調出來的(預設值是整體調過的,見手冊 §6.6),單獨改任何一個都沒有保證;validator 的範圍只防崩壞,不防音質崩壞。每列附出處(aec.h:行 為宣告,aec.c:行 為使用處)。下表欄位仍可用 AecConfig 覆寫(內部測試與 bench 會用),但屬「改了自行負責」。

3. 內部函式與 header(整合者不得依賴)

範圍內容為什麼不開放
aec_config_build.haec_resolve_valid_config、aec_build_sg_config庫內部共用的設定建構器(aec.c 與 aec_res.c);回傳的 tuning 表指向靜態 per-rate 資料。
aec_scale.haec_blocks_to_hops、aec_ms_to_hops、aec_growth_rehop、AEC_PSD_SCALE…參考常數(int16^2 PSD、4 ms 區塊)換算到本庫尺度的 init-only helper。
子模組 headerpbfdkf.h、delay_aec.h、aec_post.h、aec_state.h、suppression_gain.h、residual_echo_estimator.h、epc_shadow.h、detectors.h… 及其 *_get_mem_size／*_init_static 函式隨版本改變;應用程式只用頂層 aec_get_mem_size／aec_init(STATIC_MEMORY.md)。
suppression_gain_set_split_floor_*_far_active_db、_dt_db、_enabled是 aec_set_preset／aec_res_set_preset 的底層 primitive;整合端改用這兩個函式。
struct Aec 欄位aec.h:200 起整個攤開「欄位是內部的」只是約定,不是編譯器強制;只因 Aec 由呼叫端持有或放在 pool 內才攤開。

4. 建置期旗標(內部)

SIMD(0 → -DSIMD_KERNELS_FORCE_SCALAR)、NO_STDIO、PROFILE(-DAEC_STAGE_TIMING=1)、WERROR、EXTRA_CFLAGS、AEC_TESTING(絕不可出貨);-ffp-contract=off -fno-math-errno 由 Makefile 強制,不是選項。說明見 AEC API §11 與 AEC/c_impl/README.md。
