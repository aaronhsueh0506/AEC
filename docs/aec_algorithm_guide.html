AEC v3.22 — algorithm guide

Presentation overview for the v3.22.0 release (2026-06-01); adds the split min-gain floor (DT/NE near-end preservation, default ON) on top of v3.21. For the deep algorithm specification see aec_methods.md; for the v3.10.5 → v3.21 → AEC3 cross-comparison see architecture_v3_10_5_vs_v3_21_vs_aec3.html.

README  ·  CHANGELOG  ·  aec_methods.md  ·  pbfdkf_shadow_intro.md  ·  dtd_design.md  ·  refactor_modules_layout.md  ·  C integration

v3.21 retires the legacy 9-stage ResFilter post-filter and ships the AEC3-aligned _aec3_post chain (AecState + ResidualEchoEstimator + SuppressionGain + CNG) as the single production post-filter. Single preset: BALANCED.

3. AEC3 post-filter signal flow

The AEC3-aligned chain mirrors the WebRTC EchoRemover structure. Each sub-block runs once per hop on the post-PBFDKF error spectrum E(k).

StageOperationModule
StationarityEstimator Per-bin EMA of render PSD + CV gate; zeros R² on stationary bands; freezes refined-filter W on block-stationary frames. modules/state/stationarity_estimator.py
AecState Read-only ADT over 12 sub-analyzers (FilterAnalyzer, FilteringQualityAnalyzer, SubbandErleEstimator, ErleEstimator, ErlEstimator, FullbandErleEstimator, SaturationDetector, InitialState, TransparentMode, …); provides usable_linear_estimate for downstream gating. modules/state/aec_state.py + 12 sibling files
ResidualEchoEstimator Per-bin residual echo PSD R²(k). Linear path: R² = ERLE_subband × E². Render-based path: R² = ERL_subband × X². Reverb tail added from ReverbModel. modules/residual/residual_echo_estimator.py + reverb_model.py + reverb_decay_estimator.py
SuppressionGain Wiener-style gain G(k) = (S² - α R²) / S² with frame-state-dependent over-estimation factor α; per-bin HF cap; asymmetric attack/release temporal smoothing; spectral-floor mask. modules/residual/suppression_gain.py + suppression_filter.py
Comfort noise (CNG) Per-bin noise PSD EMA + smoothed cn gain ≈ sqrt(1 - G²); masks the suppressed spectrum so the residual sounds natural. inline in _aec3_post; mirrors AEC3 comfort_noise_generator.cc
OLA synthesis sqrt-Hann analysis × sqrt-Hann synthesis = Hann; 50 % overlap sum-to-one reconstruction; output emitted in hop-sized chunks. inline in _aec3_post

5. Configuration surface

v3.21 ships a single production preset (AecPreset.BALANCED). The override surface in AecConfig.from_preset is intentionally narrow (5 keys):

cfg = AecConfig.from_preset(AecPreset.BALANCED)
# equivalent to:
# AecConfig(
#     enable_cng=True,        # comfort-noise generator on
#     shadow_q_ratio=3.5,     # shadow Q is 3.5× refined Q (PBFDKF only)
#     shadow_mu_min=0.5,      # shadow / DT mu floor
#     warmup_frames=100,      # forced-high-mu startup window
#     kalman_q_high=1e-3,     # PBFDKF Q_high convergence speed
# )

Everything else uses AecConfig dataclass defaults; the AEC3 chain has its own tuning embedded in AecStateConfig / SuppressionGainConfig (modules/state/aec_state.py, modules/residual/suppression_gain.py).

6. Determinism + byte-equal gate

Per-case CNG seed: np.random.seed(42) before each AEC(cfg) instance. All benchmarking tooling (eval_aec_challenge.py, check_byte_equal.py, run_one_case.py) seeds before instantiation.

Every cleanup commit on the v3.21 release branch runs the 25-case byte-equal harness:

python3 python/check_byte_equal.py
# expected:
# === 25/25 PASS, 0 FAIL ===

Reference md5s at docs/bench/v3_21_3aadd2d_baseline/byte_equal_reference.json; 25 cases = 5 per bucket sampled at echo percentiles 0/25/50/75/100. Harness renders via eval_aec_challenge.py (same pipeline as production) and compares output WAV md5s for both the production _ours.wav and the enable_res=False bypass _ours_nores.wav.

8. CLI quick reference

# Single-case render (BALANCED preset)
python3 python/aec.py mic.wav ref.wav out.wav --mode pbfdkf --preset balanced --enable-res --cng

# Single-case with 5-panel diagnostic PNG
python3 python/run_one_case.py mic.wav ref.wav out.wav --preset balanced

# Per-second console diagnostics
python3 python/aec.py mic.wav ref.wav out.wav --preset balanced --enable-res --diag

# 800-case AECMOS bench
python3 python/eval_aec_challenge.py wav/aec_challenge_blind/ \
    --preset balanced --filter 832 --cng --parallel -o out_python/ --workers 4
python3 python/bench_aecmos.py out_python/ results/

# Byte-equal regression gate
python3 python/check_byte_equal.py

# C build + run
cd c_impl && make
./bin/aec_wav mic.wav ref.wav out.wav --preset balanced --cng
