PBFDKF + Shadow Filter + Multi-ERLE + WOLA RES — Acoustic Echo Cancellation

PBFDKF (Partitioned Block Frequency-Domain Kalman Filter)

核心自適應濾波器，在頻域用 Kalman 更新權重 W，估計 echo path 並從 mic 中減去：

output = mic - W * ref   (frequency domain, per-partition)

關鍵參數：

參數說明值
Q_high快速收斂（process noise）1e-3
Q_low穩定追蹤（收斂後）1e-6
P_MAXKalman gain 上限0.5
P_floorP 下限（Q_high × beta）1e-4
n_partitions分割數（fl=512 → 4）4

Kalman vs NLMS

PBFDKF 的優勢在於 per-bin adaptive step size：P[k] 大的頻段（不確定性高）學習快，P[k] 小的頻段（已收斂）學習慢。NLMS 只有全局 step size μ，所有頻段同速。這讓 PBFDKF 在 echo path 局部變化（如某頻段衰減改變）時能快速追蹤。

Shadow Filter

雙濾波器架構：main filter（保守 Q）和 shadow filter（激進 Q = main × 3.5）平行運行。

Shadow → Main Copy

當 shadow error 持續小於 main error × threshold：

  • shadow_copy_counter 累加，需 ≥ hysteresis（3 幀）
  • G3：同時需 _shadow_advantage_streak ≥ 10 幀（100ms），防止短暫 echo burst 誤觸發
  • Copy gate：error_is_normal（error 沒有異常偏高）+ far_active + !epc_active

Main → Shadow Copy（反向修正）

當 main error < shadow error × threshold，shadow 被 main 覆蓋，保持 shadow 不偏離太遠。

2. Signal Flow (Per Frame)

1. HPF (80Hz) → mic, ref
2. Saturation detection → soft-clip ref if saturated
3. Delay estimation (GCC-PHAT) → ref alignment
4. PBFDKF.process(mic, ref) → raw_output, echo_spec, error_spec
5. Shadow filter.process(mic, ref) → shadow error comparison
6. Shadow DTD compute → _dt_from_shadow
7. Echo Path Change detection → Q reset if detected
8. ERLE compute (windowed + instant) → erle_factor
9. Energy DT compute → _dt_from_energy
10. inst_erle correction → dt_indicator
11. Stationary DT detection → is_stationary_dt
12. RES.process(raw_output, ...) → final_output
13. Output limiter → clamp to avoid clipping

3. Double-Talk Detection (DTD)

DT detection 的核心問題：如何在 echo 和 near-end speech 同時存在時，保護 near-end 不被 RES 壓死。v2.3 用四個信號源合成最終的 DT 指標：

3.1 inst_erle Correction（原始 raw_dt）

基本 DT confidence 來自 far/mic energy ratio：

raw_dt = 1 - far_pwr / (mic_pwr + far_pwr)

問題：高耦合場景（mic ≈ far × coupling），FS 和 DT 的 raw_dt 都很高。inst_erle correction 用 ERLE 區分：

raw_dt /= min(inst_erle_smooth, 4.0)

Cap = 4.0 的原因（v2.1.0 關鍵修正）

高耦合 DT 時 inst_erle 可達 10-15，不加 cap 會把 raw_dt 壓到 <0.04，DT 保護完全失效。Cap 4.0 保留 raw_dt ≥ 0.15 的 DT awareness。

3.2 Pre-filter Energy DT Signal（v2.3 新增）

繞過 inst_erle correction 的死角。直接比較 mic 和 far 的能量：

max_echo_expected = far_pwr × 4.0   (+6dB ERL ceiling)
dt_from_energy = max(0, (mic_pwr - max_echo_expected) / mic_pwr)

特性：

  • DT 持續輸出 54-63%（mic 能量遠超 echo 上限）
  • FS 輸出 1-8%（mic ≈ echo）
  • EMA smoothing：fast rise（α=0.7）/ slow decay（α=0.1）
  • far_active gate：NE-only 段 far≈0 會產生 1.0，gate 歸零避免 NE→FS hangover

3.3 Shadow DTD（v2.3 重新接入）

shadow_advantage = main_err_smooth / shadow_err_smooth

DT 時 main filter 的 W 被 near-end speech 干擾，error 升高，而 shadow（更激進 Q）追蹤得更好。advantage > offset 表示 DT：

dt_from_shadow = clip((advantage - 1.5) / 3.0, 0, 1)

Offset 1.5 的設計（B2）

FS 高耦合段 shadow_advantage 1.2-1.8（convergence speed difference，不是真 DT），offset 1.0 會有 20% false positive。提高到 1.5 後只有 advantage > 1.5 才觸發，大部分 DT case 的 advantage >> 2.0，不受影響。

特性：onset 覆蓋強，持續弱（filter 過擬合後 advantage 降低）。與 Energy DT（持續強）互補。

3.4 Stationary DT Detection

專門處理 stationary far-end（白噪音、風扇、冷氣）+ near-end speech 場景。coh2 在穩態 far 全頻段高，dt_per_bin = 1-coh2 ≈ 0，正常 DT detection 失效。

檢測方式：far CV² < 0.02（stationary）時，追蹤 error power baseline。語音進入時 error 跳升（jump_ratio > 1.5），觸發 800ms hangover。

保護方式：Frequency-Shaped Mask（300-3000Hz 核心語音帶 0.8，邊緣 ramp）直接設 dt_per_bin。

3.5 effective_dt：五線驅動

所有 DT 信號匯聚成 effective_dt，驅動 RES 的五條保護路徑：

effective_dt = max(dt_for_fs, shadow_dt)
其中 shadow_dt = max(dt_from_energy, dt_from_shadow)
#路徑使用信號作用
1dt_per_bineffective_dtnearend_est 分母放大 → ENR 降低 → gain 升高
2fs_confidenceeffective_dtne_protection 和 attack speed 響應 DT
3HF cap bypasseffective_dtDT 時不壓 500Hz 以上 harmonics
4ENR threshold relaxationeffective_dtDT 時 enr_t_ne × 1.5×
5dt_temporaleffective_dt × 0.5gain release/rise 速度在 DT 響應

只接一條線無效（實驗發現）

最初只接 #4（ENR relaxation）→ 800-case DT deg +0.001。原因是高耦合 DT 的 ENR 是 10-20，放寬 1.5× 根本不夠，信號還是爆出 gate。接齊 5 條線後 #1（dt_per_bin）才是主力：nearend_est 分母直接放大，ENR 系統性降低。

4. Residual Echo Suppression (RES)

WOLA（Weighted Overlap-Add）架構的頻域後濾波器。每幀計算 per-bin gain G[k]，抑制殘餘 echo。

error × sqrt-Hann
→
FFT
→
G[k] computation
→
G × spec
→
IFFT
→
sqrt-Hann × OLA

4.1 Echo PSD Estimation

Filter-based（converged 後主要使用）

residual_echo_psd = |echo_spec|² × EMA smoothing

直接用 filter 的 echo estimate。收斂後（erle_factor > threshold）最準確。

Render-based（pre-convergence / EPC 後）

render_echo = far_psd × erl_estimate

Filter 不可信時，用 far-end PSD × 動態 ERL 估計作為 echo estimate。

B4：echo_path_gain 從 0.01 改為動態 ERL

原本固定 0.01（-40dB），實際 ERL 通常 -6~-20dB。pre-convergence 225/500 幀用 render-based，0.01 低估 10-50×，前 2.5s 幾乎無 echo 壓制。改為動態追蹤後 ERL 0.1→0.67，pre-convergence 壓制顯著改善。

Coherence-based Echo Boost（收斂後）

echo_boost = 1.0 + 0.5 × coh²   (if dt_for_fs < 0.2)

FS 場景用 coh² 加強 echo estimate，因為 coherence 高表示 error 仍和 far 相關（有殘餘 echo）。

4.2 Render-based vs Filter-based 切換

switching_threshold = 0.5 * clip(enr / (enr + 1.0), 0.3, 0.7)

// Hysteresis: 進入 render 後需更高 erle_factor 才能退出
if _using_render_based:
    effective_threshold = threshold + 0.05
else:
    effective_threshold = threshold

// G2: explicit overrides
force_render = epc_active or saturation > 0.5

// G5: minimum hold time (5 frames)
_using_render_based = want_render or (hold_remaining > 0)

為什麼 divergence > 0.5 被移除（G2 修正）

DT 期間 filter output > near-end（echo + speech），_divergence_indicator 容易超過 0.5。force render-based 會讓 RES 在本該保護 near-end 時反而用保守估計過壓 DT 語音。移除後 DT deg +0.017。

4.3 ENR Gain Computation

ENR（Echo-to-Nearend Ratio）是 v2.x 的核心 gain 計算方法：

nearend_est = max(error_psd - echo_psd, 0) × dt_sq_per_bin
ENR = echo_psd / (nearend_est + ε)
G[k] = clip((enr_s - ENR) / (enr_s - enr_t), 0, 1)

ENR 高 → echo 主導 → G → 0（壓制）。ENR 低 → near-end 主導 → G → 1（透明）。

Two-tuning（FS/NE 雙閾值）

端enr_tenr_s用途
FS0.07 × scale0.1 × scale低閾值，嚴格壓制（echo only）
NE/DT1.5 ~ 2.02.5 ~ 3.0高閾值，保護語音

最終閾值由 ne_confidence（= dt_per_bin）混合：

enr_t = ne_confidence × enr_t_ne + (1 - ne_confidence) × enr_t_fs

BUG-3 Soft Gate

FS 端 enr_s - enr_t ≈ 0.03，相當於 33× slope 的硬截斷。min_gate_width = 0.2 強制至少 0.2 的過渡帶，讓 gate 真正 soft。

4.4 DT Protection 詳解

Path 1: dt_per_bin → nearend_est

dt_per_bin = max(effective_dt, 1 - coh2)  // per-bin
dt_sq = dt_per_bin ** 2
nearend_est = max(raw_nearend * dt_sq, noise_floor)
// DT: dt_sq ≈ 0.4-0.64 → nearend_est 放大 → ENR 降低 → gain 升高

Path 2: fs_confidence → ne_protection

fs_confidence = far_activity * (1 - effective_dt) ** 2
ne_protection = (1 - coh2) * ne_erle_gate * (1 - fs_confidence)
ne_g_floor = g_min + (ne_ceil - g_min) * ne_protection
// DT: fs_confidence ≈ 0 → ne_protection 最大 → gain 下限升高

Path 3: HF cap bypass

if effective_dt < 0.5:
    g[hf_bins] = min(g[hf_bins], g[500Hz_bin])  // cap HF gain
// DT: effective_dt > 0.5 → bypass → 保留語音 harmonics

Path 4: ENR threshold relaxation

if effective_dt > 0.4:
    relax = 1.0 + (effective_dt - 0.4) / 0.6 * 0.5  // max 1.5×
    enr_t_ne *= relax
    enr_s_ne *= relax
// DT: 閾值放寬 → ENR 更容易低於閾值 → gain 更高

Path 5: dt_temporal → gain smoothing

dt_temporal = max(dt_indicator, effective_dt * 0.5)
alpha_release_light = 0.5 - 0.2 * dt_temporal
// DT: release 更快 → 語音恢復更快
// 0.5× 係數避免過度激進

4.5 Temporal Smoothing

Split attack/release with rate clamping：

// Attack: heavy EMA (smooth onset)
alpha_attack = 0.3 * far_activity + 0.5 * (1 - far_activity)
// Stationary DT: alpha_attack *= (1 - dt_temporal²) ≈ 0.36

// Release: light EMA (fast recovery)
alpha_release = 0.5 - 0.2 * dt_temporal

// Rate clamp: max 6dB/frame drop, 6dB/frame rise
gain_change = clamp(new_gain - prev_gain, -max_drop, +max_rise)

4.6 Post-processing

  • Cross-frequency smoothing：3-bin kernel [0.25, 0.5, 0.25]，減少 musical noise
  • EMR noise masking：echo 低於 noise floor 的 bin 不壓制（echo 已被 noise mask）
  • spectral_g_min：保持殘餘 noise shape（envelope-weighted floor）
  • Divergence override：divergence > 0.3 時全局 cap gain
  • CNG：comfort noise = sqrt(1 - G²) × noise_psd

5. Echo Path Change (EPC)

當 echo path 突然改變（設備移動、門開關等），filter W 瞬間不合，需要快速重新收斂：

delta_err = |main_err - shadow_err|
total_err = main_err + shadow_err
if delta_err / total_err < 0.3 and total_err > prev * 1.5:
    // 兩個 filter 同時 error 上升 → echo path change
    // (DT 是一個 filter error 上升，另一個穩定)
    trigger EPC:
      Q → Q_high (fast re-convergence)
      P_max_override = 1.0 (30 frames)
      P_floor_beta = 1.0 (30 frames)
      _filter_converged = False
      _epc_render_forced = 20 frames (G1)
      _erl_estimate = min(erl, 0.3) (A4)

6. Dynamic ERL Estimation (B4)

Pre-convergence 時 filter echo estimate 不可信，RES 用 render-based mode。ERL（Echo Return Loss）決定 echo 估計的準確度：

inst_erl = clip(mic_pwr / far_pwr, 0.001, 1.0)
erl_estimate = 0.99 × erl_estimate + 0.01 × inst_erl

Gate：僅在 pre-convergence + far_active + raw_dt < 2.0（echo-dominated）時更新。DT 時 mic_pwr 包含 near-end speech 會高估 ERL。

7. Delay Estimation (GCC-PHAT)

Online delay estimation，每 0.5s 重新估計。首次估計在 300ms 後：

cross_spec = alpha * cross_spec + (1-alpha) * mic_spec * conj(ref_spec)
phat = cross_spec / |cross_spec|
gcc = IFFT(phat)
delay = argmax(|gcc[0 : max_delay]|)

PAR Confidence Gate（A5）

Peak-to-Average Ratio > 5.0 才 accept。DT onset 時 GCC peak 不可信（near-end speech 干擾 cross-correlation），PAR < 3。純 FS 時 PAR 通常 20-50。

首次 Delay Reset（B3）

首次 delay 確認後，filter W（學了 300ms 錯誤 alignment）需要 reset，包括 PBFDKF W/P、shadow filter、ResFilter PSD/coh2。Q 重置為 Q_high 加速重新收斂。
