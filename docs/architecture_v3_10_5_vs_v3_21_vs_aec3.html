AEC architecture comparison — v3.10.5 vs v3.21 vs WebRTC AEC3

Generated for the v3.21.0 release (2026-05-19). Anchors: v3.10.5 was the last release before the AEC3 fetch cycle (Phase A.1 delay subsystem onwards); v3.21 is the current production release; WebRTC AEC3 is the canonical reference architecture (Chromium modules/audio_processing/aec3/).

The v3.21 release is the first to ship the AEC3-aligned residual path as the only post-filter. v3.10.5 — v3.20 ran the legacy 9-stage ResFilter as the production post-filter while the AEC3 chain (state / residual / filter / render subpackages) was being built up behind the use_aec3_residual flag. v3.21 retires the legacy chain, drops the flag, and ships BALANCED as the single production preset.

3. Configuration surface (BALANCED preset)

v3.10.5

Five operating points (MILD / SOFT / BALANCED / AGGRESSIVE / MAXIMUM), each with ~40 RES knobs co-tuned per preset (over-sub base / scale, ENR thresholds, spectral floor, gain rate caps, NE-protect thresholds, mask profiles, etc.) plus shared kalman / delay / DTD knobs.

v3.21

Single production preset BALANCED. The legacy 5-preset table and ~40 RES knobs are deleted; the AEC3 post-filter is hard-tuned per AecStateConfig defaults (modules/state/aec_state.py). The five overrides that remain on a live consumer: enable_cng, shadow_q_ratio, shadow_mu_min, warmup_frames, kalman_q_high. Everything else uses dataclass defaults.

WebRTC AEC3

Single config struct (EchoCanceller3Config) with ~150 fields exposed through echo_canceller3_config_json.cc. The Chromium build wires Field Trials to override specific fields per platform / scenario; there is no preset enum. v3.21's pattern matches AEC3 in spirit — one default tuning, no preset menu.

4. What changed v3.10.5 → v3.21

Area What v3.10.5 had What v3.21 has
Post-filter ResFilter 9-stage residual echo suppressor (2 200 LOC); per-bin gain assembled from coh², ENR, spectral mask, quiet mask, HF cap, etc. _aec3_post calls AecState + ResidualEchoEstimator + SuppressionGain + per-bin CNG; AEC3 Wiener gain on a 2-path residual echo PSD estimate.
Delay estimator GCC-PHAT with 1024 ms max delay (v3.10.4 widening); fixed accumulation period. AEC3-aligned EchoPathDelayEstimator (matched filter + lag aggregator over 13-second window) + clock-drift detector + render delay controller. Legacy DelayEstimator public name kept as a shim around the new estimator.
Filter convergence ADT Local FilterConvergenceAnalyzer 10-frame ERLE latch. FilterConvergenceAnalyzer retained for backward-compat; AecState + FilteringQualityAnalyzer + InitialState + FilterAnalyzer provide the AEC3-aligned multi-gate decision used by the AEC3 chain.
Render-signal mask Absent — refined filter learned against narrowband tonal renders the same as broadband. RenderSignalAnalyzer identifies narrowband tonal regions in the render history and (a) produces a per-bin freeze mask for refined-filter gain compute and (b) gates the W update via poor_signal_excitation.
Reverb tail Inline 1-tap exponential decay in ResFilter._stage_1. AEC3 ReverbModel + decay estimator + frequency response wired into ResidualEchoEstimator; tracks per-bin reverb energy across the impulse response tail.
Sub-band ERLE Fullband only. SubbandErleEstimator per-band EMA (AEC3-style) drives the SuppressionGain ERLE-divide refinement.
Five-preset menu MILD / SOFT / BALANCED / AGGRESSIVE / MAXIMUM. Single BALANCED preset; v3.21 cleanup R1 deleted the others.
~40 RES knobs res_g_min_db, res_over_sub_base / scale, res_dt_reduction, res_echo_method, res_gain_type, res_enable_reverb, res_alpha_echo_psd / error_psd, res_enr_scale, res_mask_*, etc. Deleted (R10a). AEC3 chain has its own tuning under AecStateConfig / SuppressionGainConfig.
Arc G / Arc T substrate (absent — these arcs were added v3.14 / v3.15) Tried v3.14 / v3.15, closed CANNOT-SHIP, retired with the post-filter loop. Removed in v3.21 cleanup R6 / R10b.
Per-band ERL EMA (Arc P) (absent) v3.14 Arc P P.S2 EMA + v3.15 Arc G drift detector retired in R6 / R10b. The constant [0.1, 0.1, 0.1] broadcast into filter._erl_per_bin is the only remaining trace.
v3.18 Phase C / D / F substrate (absent) Audit-only AecState ADT + FilterAnalyzer + FilteringQualityAnalyzer + subband-NE detector + AEC3 event classification + mask profile swap shipped as substrate during v3.18; closed CANNOT-SHIP; flags retired in R10b-2 / R10c.
HPF defaults Both HPF ON. Far-end (ref) HPF=OFF, mic-path HPF=ON. Locked by user directive after the v3.19 HPF-flip verdict.
Shadow filter class PBFDKF clone (same class as main). NLMS (PBFDAF) by default — v3.21 Phase B.1 promoted shadow_class_nlms=True; AEC3-aligned coarse filter role.
Filter misadjustment estimator (absent) v3.21 Phase B.5 filter_misadjustment_enabled=True default ON; long-term echo/error ratio drift triggers ScaleFilter rescale of main W.
