What's gone (v3.10.5 → v3.21)

  • ResFilter 9-stage chain — 2 200 LOC, retired in R7. −2 200
  • Preset menu — MILD / SOFT / AGGRESSIVE / MAXIMUM gone; only BALANCED ships. −210
  • ~40 RES knobs — res_g_min_db / res_over_sub_* / res_dt_reduction / res_echo_method / res_gain_type / res_alpha_* / res_mask_* deleted. −300
  • Reference HPF — bypass by default since v3.19 ref-flip verdict.
  • Arc P / Arc G / Arc T substrate — per-band ERL EMA + drift-detect + cohort-tail detector — retired R6 + R10b.
  • v3.18 Phase C / D / F substrate — AecState facade / leakage_diverged / branch ablations / mask shape swap / NE detector substrate — retired R8 + R10c.
  • ~130 verdict / design docs from v3.11 → v3.20 closed-arc record — moved to summary form (R11 + R13). −32 k lines

What's new (v3.10.5 → v3.21)

  • AEC3-aligned post-filter — _aec3_post() = StationarityEstimator + AecState + ResidualEchoEstimator + SuppressionGain + CNG + OLA. single path
  • AEC3 delay subsystem — matched filter + lag aggregator + clock-drift detector + render-delay controller (replaces GCC-PHAT).
  • AecState ADT — read-only seam over 12 sub-analyzers (FilterAnalyzer / FilteringQualityAnalyzer / SubbandErleEstimator / StationarityEstimator / etc.).
  • RenderSignalAnalyzer — per-bin narrowband tonal mask + poor-excitation freeze.
  • ReverbModel — explicit reverb tail in residual estimate.
  • Sub-band ERLE — per-band EMA drives SuppressionGain ERLE-divide.
  • Shadow NLMS — coarse filter = PBFDAF (NLMS), default ON since v3.21 Phase B.1.
  • FilterMisadjustmentEstimator + ScaleFilter — long-term echo/error ratio drift → rescale W. Default ON since v3.21 Phase B.5.
