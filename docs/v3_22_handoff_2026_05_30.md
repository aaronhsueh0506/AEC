## 決策記錄（本 session 的重要判斷）

1. **Bug fix bypass score-gate**：E1/x2/E2 是 correctness fix → 直接 default ON，不 deg-Pareto gate（「看問題有沒有解掉，不是看分數」）
2. **E1 DT deg −0.05 = 意外保護消失**：buggy ERLE 虛高 → 意外壓制 R² → 意外保護 near。修正後 near 保護消失。應由 A1 explicit 保護來替代，**不是**把 E1 reverting
3. **x2-scale 重測的再審效益**：舊 verdict DT −0.05 在 buggy baseline 上；E1-ON baseline 重測後降到 −0.02 → 可負擔。這是「buggy baseline 上的測試結果無效」的第一個直接體現
4. **A0/A1 是 upside 不是 necessity**：AEC3 reference 顯示我們的 DT deg 已 BEAT AEC3（+0.15/+0.27），echo 才是真缺口
5. **E2 不是 negligible**：gate 開 30.8%，火 10.6%，FS_movement 41%；≈0 AECMOS 是因為 diverged frame gain 已 ≈0 兩邊都一樣，不是 gate 沒打開
6. **E2 audit 更正（2026-05-30 code scan）**：handoff 解釋「gain ≈ 0」**有誤**。suppression_gain.py 唯一 gain=0 路徑是 `saturated_echo=True`，與 usable_linear 無關。真正原因：E→Y 切換移除 corrupted residual（好）但同時移除 linear echo suppression 貢獻（壞），net wash。Port 正確，code comment 已補 (`orchestrator.py:3475-3496`)。
7. **架構 audit 結論（2026-05-30）**：
   - `subband_erle.py:148 |=` — AEC3-canonical（reference line 253-254 相同），不是 bug
   - FilterQuality._RESET_HOPS=20 hops (200ms) = EPC grace period 已存在，AEC3-canonical
   - partition_sum X² HF trace：bimodal (p50=2.34)，reverb tail 物理，無 starvation
   - **唯一 open item**：candidate-B + W4 bench pending
