pocketfft — vendored from numpy 1.26.4 (numpy/fft/_pocketfft.c).

Only the pure-C real-FFT (rfftp) path is kept (pocketfft.c / pocketfft.h);
the cfftp / Bluestein / numpy Python-wrapper code is stripped. The FFT math is
byte-for-byte identical to the upstream source. 3-clause BSD license below.
